# Dart 官方第一手资料

**分层说明**：规范形式、语言教程、风格建议与工具诊断分别具有不同约束力。通过在线查询核对的官方入口：

- [Formal language specification（Dart 3 in progress）](https://dart.dev/resources/language/spec) — 形式规范状态；不能将尚未更新部分当作已覆盖。
- [Language landing](https://dart.dev/language) — 语言主题索引。
- [Language evolution](https://dart.dev/resources/language/evolution) — 版本与特性。
- [Class modifiers](https://dart.dev/language/class-modifiers) — 类能力、限制。
- [Records](https://dart.dev/language/records) — 结构化 Record 类型。
- [Patterns](https://dart.dev/language/patterns) — 模式匹配与解构。
- [Pattern types](https://dart.dev/language/pattern-types) — 具体模式语法。
- [Type system](https://dart.dev/language/type-system) — 类型与静态检查。
- [Effective Dart overview](https://dart.dev/effective-dart) — 推荐总则。
- [Effective Dart style](https://dart.dev/effective-dart/style) — 风格和命名。
- [Effective Dart documentation](https://dart.dev/effective-dart/documentation) — `///` API 文档。
- [Effective Dart usage](https://dart.dev/effective-dart/usage) — 语言使用建议。
- [Effective Dart design](https://dart.dev/effective-dart/design) — API/名称语义。
- [Analyzer](https://dart.dev/tools/analysis) — `analysis_options.yaml`/严格类型检查。
- [Linter rules](https://dart.dev/tools/linter-rules) — 全规则列表（随 SDK 变化）。
- [Dart formatter](https://dart.dev/tools/dart-format) — 官方自动格式化与版本边界。

专题矩阵中的 URL 是建议在目标 SDK/联网环境中按需逐条访问的官方页，不保证其所有路径今后不重定向。
