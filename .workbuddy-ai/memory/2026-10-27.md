# 2026-10-27

## 教务课表抓取脚本（output/curriculum/）

用户要抓取重庆移通学院智慧教务课表（`zhjw.cqytxy.edu.cn/workspace/curriculum`，账号 2026236424，26 软工 204 班，2026-2027-1 学期）。

### 实测得到的关键事实（勿凭猜测推翻）

- **教务系统不对外网开放**：所有路径（`/`、`/login`、`/api/*`）均 302 到 `vpn.cqytxy.edu.cn`。校外必须过 WebVPN，代理后路径为 `/https/<加密串>/...`。
- **登录是 CAS 统一身份认证**：`/authserver/login`，密码经前端加盐写入 `<input id="saltPassword" name="password" type="hidden">` 提交。
- **验证码是条件触发的**：`#captcha` 配合 `onfocusout="checkUserCaptcha()"`，输完学号才决定是否显示。所以用户"平时没见过验证码"与页面有验证码字段并不矛盾。
- 登录页 SPA 渲染较慢，`wait_until="networkidle"` 会超时，需用 `domcontentloaded` + 固定等待。

### 技术选型结论

放弃「脚本填账号密码自动登录」：要复现盐值加密 + 条件验证码，维护成本高且脆弱。
改为 **人工登录一次 + Playwright 持久化 profile 复用会话**，绕开登录与 URL 加密，只负责取数据。

### 产出

- `fetch_curriculum.py`：持久化上下文 → 等登录 → 监听 JSON 响应 → 落盘 `raw/` + `data/summary.json`
- `README.md`：环境准备与用法
