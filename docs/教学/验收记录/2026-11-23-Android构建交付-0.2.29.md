## 构建过程与失败记录

1. 首次 `cd android && ./gradlew :app:assembleRelease --offline` 失败：`:app:compileReleaseJavaWithJavac` 报 `程序包 dev.flutter.plugins.integration_test 不存在`。
2. 第二次 `flutter build apk --release --target-platform android-arm64 --no-pub` 同样失败，原因相同。
3. 定位：`--no-pub` 跳过 `pub get`，而 release 模式的插件注册表刷新（`refreshPluginsList(releaseMode: true)`）会过滤 dev 依赖；被跳过时 `GeneratedPluginRegistrant.java` 仍是 debug 形态，含 `integration_test`，但 Gradle release 侧的 `PluginHandler` 明确排除 dev 依赖，于是类缺失。
4. 第三次去掉 `--no-pub` 重新构建，`pub get` 离线命中缓存、`pubspec.lock` 未变化，构建成功。**结论：本机离线出包必须让 Flutter 工具自己刷新 release 注册表，不能只用 `--no-pub` 或直接跑 Gradle。**
