## Agent 功能变化

1. 多服务与多模型目录。每个服务分别设置地址、Chat Completions/Messages 协议及 Key，支持无 Key 本机服务。获取模型列表后搜索选择，支持分页、取消和手动补充编号。
2. 模型配置和选择。可设置上下文、回复预算、输出硬上限、图片能力、思考程度及供应商适配。默认主模型、全局摘要模型和当前会话主模型分别选择，模型和服务可停用或恢复。
3. 消息分支。用户消息可编辑后重发，消息可从指定位置建立新分支，最后回答可重新生成。含工具调用或结果的轮次提示使用编辑后重发，原会话保留。
4. 分支恢复和附件。任务/目标/节点引用随分支保存，切换或重开仍恢复关联范围。编辑重发保留图片和文本附件，已完成回答的分支保留轮次结束状态。
5. 角色定位与回答风格。可使用预设或自定义正文，随助手设置保存并用于后续对话。
6. 协议与设置可靠性。修正 DeepSeek 思考参数和 Messages 路径，无 Key 服务跳过凭据读取。Key 替换与清除采用版本引用提交，保存失败保留有效配置。服务编辑统一保存草稿，放弃停用可撤销。

详细修复和后续能力见[修复记录](../../审查/2026-11-14-助手模型与分支修复.md)及[实施计划](../../设计/Agent能力升级/工作包与验收.md#实施状态)。结构化追问、输入队列、技能、后台作业和子智能体仍按计划推进。
