# 2026-10-31 任务状态与操作入口

根据用户手机尺寸页面截图及试用反馈修复执行详情与事后操作混用，追加“结束默认选中已完成”、统一 UI、称呼、AI 日记本和分层自动总结设置。基线 `854831d`，数据库 v15。本轮不变更 schema，不修改旧事件或材料。

## 规格与实现

- 未启动未过期、执行中、暂停、STOP 待确认的方案详情不展示事后评价、补记、记录或材料编辑；执行信息页返回同一执行页/报告页。
- 固定整个计划时段已过且无执行事实、自选跨计划日，统一按 missionAttention 进入待处理。首次打开弹出完成确认，默认已完成，可改选未执行/未完成或稍后处理；改期、现在补做仍可用。
- 点击确认后才保存 END 和用户时间声明，无 START 时不造 START。固定预填时段明确展示并由用户认可，自选默认未知；切换未执行不继承计划时长。
- 普通结束、STOP 待确认也默认选择已完成；只改变草稿，确认前没有 END。修改原因/结果/材料选择的草稿保留丢弃保护。
- 结束后使用统一白色卡片行查看记录、更正实际时间和添加/补充材料；评价折叠于白色分区。主确认实心、次操作描边，禁止新操作以裸文本按钮堆叠。
- 领域材料写入能力仍支持独立记录随时关联任务，关联不意味着结束。已关闭补充、取消、原材料超时和完成报告均保留原事实。
- 助手“对我的称呼”沿既有角色设置持久化，进入新会话、原会话与重开会话的模型提示；称呼只是文字，不额外改变权限或任务事实。
- AI 日记本复用 MemoryEntry / MemoryService，支持搜索、过期筛选、来源展开、更正和忘记。搜索设置按统一卡片重排，补齐加载失败、额度校验、移除确认，连接测试使用已保存 Key。
- 自动总结按记录、任务、节点、目标独立控制；关闭后仍保存事实和来源失效，停止对应层自动模型请求。没有总结时直接显示生成按钮，手动请求在原队列持久化，父级更新仍遵守开关。
