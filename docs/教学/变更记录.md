## 2026-11-02：固定任务绑定计划起止时刻

用户明确固定任务必须从计划开始时间计时，并在固定终点停止，只有执行期间明确增加时长才顺延。原自动 START 使用事务唤醒时刻；统一计时只看 START，打开应用较晚就少算此前时段；原终点规则还允许整个窗口过后开始时重新取得完整预算。

替代为：固定 START 在事务中核对当前仍在计划窗口后绑定计划起点，固定终点集中为 fixedTimeSlotEnd（起点 + 原计划 + 已保存 EXTEND）；移除迟到 START 重新取得完整预算的规则。禁止固定任务提前或窗口结束后直接开始，现有改期、现在补做和历史补报仍保留；已有运行任务不会被抢占。调度在异步重读期间跨过窗口结束时跳过候选，避免回滚此前已处理的 STOP。

calculateExecutionTimes 接收原排期，固定计时从计划起点累计并在固定终点封顶，暂停仍扣除专注。全量生产调用及共享实时时长组件同步传入排期，覆盖日程、当前任务栏、执行/报告、记录、历史、个人统计、通知、时间轴和助手任务投影；日程剩余时间、进度及当前时段也读取真实 EXTEND。旧事件不覆写，旧 START 的迟到不再改变显示计时；旧末次动作晚于终点时仍保持追加日志有序，时长由计划窗口封顶。

保留唯一执行时间线、deriveMissionPhase 完整生产查询、STOP/END 区分、预期序号、命令身份、锁和事务；没有修改数据库结构，也未将计时当作用户完成或真实投入证明。格式化、静态分析与 Web 编译结果见学习进度，本轮未新增或运行测试；设备后台唤醒、重启、暂停和加时行为仍需实际验收，用户掌握未标记。
