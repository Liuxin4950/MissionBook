# 助手 UI 适配修订

用户反馈：不同设备适配、聊天记录间距和语音界面需要重做。用户明确要求只调整新增 AI 模块，已有任务、目标、今天页界面保留。本图仅用于 AI 模块视觉参考，右侧任务列表、附件入口与导航不作为实施内容。

使用内置 image_gen 生成一张参考板，正式图片：[设计参考](../assets/assistant-ui-rework-20261029/00-design-reference.png)。检查结果：中文主体可读，手机对话/会话列表与平板语音浮层关系清楚；图中日期、重复会话及任务内容为示意数据，不作为实际功能证据。

实施选择：消息气泡独立限宽、轮次间距和正文行距统一；查询操作显示紧凑行；会话记录按日期分组、支持标题/会话类型搜索与更多菜单；语音转写直接显示，改文字仍进入二级聊天页，不在浮层叠放表单。录音状态来自真实控制器，不绘制虚构音量波形。

实际 Flutter 截图在同目录 01—12；由 Widget 测试渲染，覆盖手机、平板横竖屏和分屏键盘。生成图不替代实际截图和设备验收，真机系统语音服务仍需用户测试。
