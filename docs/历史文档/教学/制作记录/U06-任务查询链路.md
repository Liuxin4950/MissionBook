- App 的 State 在 initState 创建数据库、DriftMissionRepository 和 CreateMission，页面逐层传递同一个业务对象。
- MissionRepository 当前只有 create；查询入口、仓储查询方法和真实列表尚未实现。
- 用户已添加顶层函数 missionFromRow，尚无查询调用者；该文件 dart analyze 通过。此结果不等于查询或设备验证通过。
- 查询按当前排期（每任务最大版本）筛选所选日期；日期和分钟来自排期，标题来自任务。
