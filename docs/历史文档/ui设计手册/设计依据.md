## 已采用的取舍

- 手机先支持当页主要判断和动作，文字辅助图形；不将路径、Why、完整方案和统计全部塞入首页。
- 今天使用紧凑时间节点，位置表达先后，卡片高度不编码分钟；当前任务可突出，其他项紧凑。
- 目标图形表达直接完成记录覆盖，不表达掌握度，不自动达成目标。
- 树用缩进、连接线、展开箭头表达层级；父节点自身状态与子树计数分开。
- 中性底色与深灰正文建立阅读层级；森林绿只承担小面积主操作和品牌，柑橘为少量当前状态。纸艺插画仅用于空态，普通筛选和导航采用浅面。研究依据和取舍见[2026-10-26审查](制作记录/2026-10-26-颜色层级与空态审查.md)。
- 动效解释展开、切换、返回和状态变化，不循环装饰，并遵循系统减少动效。
- 任何功能按[三步交互原则](三步交互原则.md)审查完整必经路径，不能只算到入口。
