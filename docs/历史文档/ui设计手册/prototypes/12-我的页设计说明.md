# 我的 — 当前单页原型

使用内置图片生成工具，以当前历史页作为风格和导航参考，只生成本页一张图。依据[Me规格](../../需求文档v1.0/界面与交互.md#11-history-与-me)、[平台能力边界](../../需求文档v1.0/数据落地与平台.md#73-平台验收边界)及[颜色与布局规范](../颜色与布局规范.md)。

## 页面只回答三个问题

提醒是否可用、数据怎样导出、这是什么版本。通知能力用一个柑橘提示面突出，准时提醒为开放行；本地备份集中说明范围并提供导出，关于原位展开。四项导航选中“我的”。不放头像、账号、成长值或假统计填空。

所有功能标题18/24，页标题28/36，区块与按钮16/24，辅助14/20，导航12/16。延续暖白、森林绿、柑橘、圆形图标和胶囊操作；同级功能名同字号。填充面上用主文字或主色，次文字用于暖白/白色面。生成图的字形、边界和颜色为近似，真实实现遵守统一JSON，不能采样图片代替参数。

## 当前图示例

这是Android未授权能力的设计样例：通知未开启，准时提醒需要系统授权；不是对当前电脑或任何真机的检测结论。“固定时间任务可能无法提醒”与“去设置”说明当前可做的操作，不用假开关代替系统状态，也不因无权限阻止保存任务或手动执行。

备份处于空闲、尚未导出的样例状态。按钮启用，但没有虚构备份成功、最近导出时间或文件大小。旁边先说明“包含数据与正式附件，不含草稿”，再由用户触发导出。关于版本0.2.2（4）取自本轮读取的pubspec.yaml；实际运行时使用安装包版本，不把静态图作为版本源。

## 系统设置与平台变化

通知授权和精确调度是两项独立能力，每项“去设置”直接请求/打开适用入口，返回原行重新查询。已授权显示真实可用状态及必要系统限制；不支持或无法查询时明确说明，不默认画成绿色正常。用户拒绝、系统限制和调度失败可分别呈现，并允许重查，不撤销任务事实。

Windows复用同一视觉骨架，按实际通知适配及分发能力显示；不照搬Android精确提醒授权行或承诺退出后仍可提醒。Android强行停止及厂商省电限制保留准确说明，详细原因在当前权限区域按需展开。

## 备份、关于与三步

备份范围为一致数据库快照、全部正式附件与格式说明，不包含未提交草稿。发起、准备、保存、成功/失败均在本地备份区域更新；阻止重复导出。已知总量才显示确定百分比，未知总量显示正在处理的阶段；成功才显示实际保存位置，失败说明原因并给重试，不修改源数据。取消系统保存返回空闲，不标成功。

从任一顶层→我的第1次；直接系统保存选择第2次；必要返回第3次；进度和结果原位反馈。权限设置同样是我的1次→对应系统入口2次→返回3次；通知和准时提醒是各自独立可完成操作，不强迫串行授权两个系统页。关于在原行展开0次。用户操作数可以超过3，限制针对页面跳转，不省略必要授权或保存。

关于展开品牌、实际版本和本地应用说明；不增加未定义的登录、云同步、AI配置、主题选择、恢复导入、清空数据或购买入口。Goal大纲JSON导入仍属于目标页，不混入备份区域。

## 动效与交付检查

原位展开360ms、透明度180ms、按压140ms，遵循减少动效；状态刷新保持焦点及原位置。导出按钮尺寸不随进度文案变化；关于内容、大字体和系统返回后说明可滚动，正文不被底部导航遮挡。
