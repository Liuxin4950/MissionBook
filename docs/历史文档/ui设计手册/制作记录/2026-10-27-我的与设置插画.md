# 我的与设置：纸艺插画制作记录

用户希望用更有层次的语义图片替代生硬的通用图标。本轮使用内置 imagegen 工具生成三张透明 PNG，参照既有目标纸艺的纸张质感、暖白与森林绿；不含文字或虚构业务数据。素材作为内容装饰，具体数值、状态和可操作按钮依旧由真实数据及文字承载，并排除重复读屏。

- `assets/illustrations/profile-notebook.png`：个人资料卡，打开的奶白纸质笔记本、空白资料卡与深绿书签。提示词：`transparent UI illustration ... open cream notebook with a blank simple paper profile card ... dark forest-green ribbon ... small muted sage leaf ... paper-craft ... no text`。
- `assets/illustrations/settings-notebook.png`：设置权限摘要，纸质笔记本与调节旋钮。提示词：`transparent UI illustration for app settings ... cream paper notebook with a simple forest-green mechanical dial ... tactile layered paper ... no text`。
- `assets/illustrations/focus-hourglass.png`：累计专注统计，纸艺沙漏。提示词：`small transparent illustration for a focus time statistic ... miniature hourglass made of cream textured paper and muted forest-green base ... no numbers, letters or logos`。

三张素材由内置生图生成后直接复制到项目；未覆盖原有素材，保留透明通道。生成图不代表用户头像、提醒送达或任务执行状态。页面截图使用隔离测试数据，需在目标 Android 平板和 Windows 上继续验收。
- `assets/illustrations/profile-paper-background.png`：个人资料卡背景。提示词：`almost-white warm ivory handmade paper ... extremely faint natural fibre texture ... pale sage leaf silhouettes in far upper right ... uncluttered low-contrast negative space ... no text`。实际展示叠加85%白色遮罩；对原图各通道最暗值合成后的保守下限计算，次级正文 `#626A64` 对比度约4.585:1。该计算仅覆盖素材与指定颜色，不等同全应用或设备无障碍验收。

## 本轮设计依据

- [Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：按阅读顺序组织重要内容，利用对齐和分组表达层次，并适应窗口与字体大小变化。本轮把资料、统计、真实目标和近期记录分组，文本按阅读方向左对齐。
- [Android 大屏布局](https://developer.android.com/guide/topics/large-screens/user-interface)：使用随窗口变化的多栏与辅助面板。本轮按实际内容宽度、字体缩放重排，不以设备型号固定布局。
- [W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)：以普通文字4.5:1作为背景可读性的参考；素材最深处对正文可能造成干扰，故在显示层使用浅色遮罩并计算保守下界。
