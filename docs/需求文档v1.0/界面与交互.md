# Mission Book — 界面与交互

视觉布局参考[UI 设计稿](../ui设计手册/README.md)，业务行为遵循[领域模型](领域模型.md)。设计稿中的历史功能示意不扩大当前范围。本文件定义当前版实际显示和操作，不保留模拟评价界面。

## 1. 视觉与文案

Mission Book 的主标语是“让每一个行动，通向更好的自己。”，英文品牌语为 Turn direction into action. / A better you, one mission at a time.。Plan / Act / Grow 表达看清方向、专注执行、持续成长，不表示当前已有 Plan 编辑器。

界面统一引用[颜色与布局规范](../ui设计手册/颜色与布局规范.md)和[唯一颜色定义](../ui设计手册/assets/正稿v1.1/design-tokens.json)：暖白#F7F8F2、森林绿#244D3D、柑橘#D7F57B，全部使用平台无衬线字体。通过位置、留白、圆形动作、胶囊控件和细分隔表达层级；新增入口为页面标题区的圆形按钮，主要提交为胶囊按钮。普通列表任务名和区块标题16/24，输入值与详情计划主值18/24；详情主体任务名使用页面标题层级。页面标题28/36，控制16/24，辅助14/20；执行主Focus单独48/56，冻结摘要28/36，不按内容随意改同级字号。

页面标题、导航、按钮、输入标签、帮助、错误和日期选择器使用中文。Today / Goals / History / Me、In Mission、Result 是文档中的页面代号，实际显示“今天 / 目标 / 历史 / 我的”“执行任务”“执行记录”。Why / What / How / Verify 可作为次级装饰英文，必须同时有中文标签。品牌名与用户内容不强制翻译。

语气陈述事实，不评判用户；不使用金币、等级、签到、排行榜。已提交材料不显示“Verified / 已通过验证”，覆盖率不显示“已掌握”。

## 2. 信息架构与导航

```text
今天 Today：当前执行、所选日期任务、待处理入口、活动概览
目标 Goals：目标列表 → 目标详情与节点树 → 节点任务
历史 History：执行记录 → 结果页 / 待补材料
我的 Me：本机个人资料与行动概览；右上角进入设置、提醒权限、本地备份与关于
```

任务页面按职责分为详情、执行任务、执行记录，原型只参考视觉层级，实际编排同时考虑入口意图与业务状态。今天页点击已结束任务先进入完整任务详情，保留原计划、Why和行动方案，再通过“查看执行记录”进入结果，返回仍是原详情。运行/暂停任务与全局当前任务入口直接进入执行页，历史的已结束行直接进入记录页。开始和结束成功后替换同一任务的当前路由，返回直接回来源列表；结束报告在执行页内切换。执行页和记录页都可临时阅读只读任务详情，再返回原页面实例，不重复堆叠相同任务的执行页或记录页。

四个顶层页保持各自导航与滚动状态；任务子页使用正常返回栈，不重复堆叠底部导航。系统返回、页面返回与关闭编辑页使用相同的未保存内容提示。

顶层列表负责显示任务身份、阶段和必要摘要，不放执行圆环、报告或材料编辑工作区。目标卡可展开路径和节点任务摘要；运行或暂停的任务从今天、目标节点、全部任务列表及底部当前任务快捷栏进入同一个独立执行页。未开始任务进入详情，再由“开始任务”进入执行页；历史记录进入独立记录页。12张图表达阅读或工作状态，不要求12条串行路由。

任何顶层有RUNNING或PAUSED任务时，导航上方提供条件式当前任务快捷栏：优先RUNNING，再最近PAUSED；可查看其他暂停任务。点击快捷栏直接进入独立执行页，不绕今天；点击各列表里运行或暂停的任务也进入同一页。无执行任务时不显示空壳。离开执行页不自动暂停；任务状态与Focus由持久化事件重读。

2026-10-26 双栏与反馈补正：主导航切换先处理右栏离开守卫，允许后清空右栏再切换主页面，不在遮挡页面下面偷换。主列表选择另一任务/目标替换右栏链，右栏内部的详情/编辑/记录保留逐级返回；通知可在未保存页面上方进入，返回继续原草稿。工作区间隙使用页面背景；仅阅读表面限宽，整个应用填满实际窗口。紧凑当前任务栏在主工作区底部，手机位于导航上方，多个暂停任务点击选择器查看，不在顶部常驻展开。操作反馈用底部浮动 Snackbar。自选、全部任务和短时任务阅读项共用六阶段图标，图标底36、图标22，行高由实际文字撑开。该段优先于旧截图和旧图标尺寸说明，具体实现及设备验收见[修复说明](../开发/布局反馈与通知修复.md)。

## 3. 启动与错误

启动页短暂展示品牌与旅程插画，不用虚构进度条掩盖未知加载。数据库初始化、迁移及截止补算完成前显示可解释的加载状态；失败显示原因、重试和错误详情入口，不永远停在品牌页。

开始展示业务数据后，不注入示例任务或假评分。通知对账失败可单独提示，不阻塞已经可用的任务记录。

## 4. Today

### 4.1 布局与当前任务

上方显示页面标题和所选日期，主体为紧凑计划顺序；当前任务行突出标题、计划投入与主操作，Goal路径（独立任务显示“临时任务”）、Why和方案按需原位展开，不在首屏叠加长说明。待开始显示最新排期的“计划时长”；已有 START 才显示原计划、当前额度与 Focus。活动统计位于任务列表后方，不挤占日程主视觉。

执行任务的当前强调只展示一条：优先全局 RUNNING，其次最近暂停的 PAUSED，最后所选日期中已有“可以开始”标签的 NOT_STARTED。同一任务在日程内已经突出时不另建重复当前卡；跨日任务用持续可见的简洁快捷栏。多个暂停任务通过底部当前任务栏的选择器查看。日期不影响正在执行任务的可见性；没有合适任务显示明确空状态和创建入口。

2026-10-23 已验收的今天页排期布局：标题和日期入口下方为七天快捷选择；切换周内日期和日历共用日期查询，创建沿用所选日期。主体依次为“计划日程”“自选时间”“安排概览”。两个任务区常驻；没有任务时保留标题和实际入口，不制造占位任务。

- 固定日程按 fixedStartAt、id 稳定排序；自选按未开始、执行中/暂停、待补材料、已结束分组，同组保留创建时间、id 顺序（2026-10-24 调整），避免已结束项占据折叠前的三个位置。固定日程首页按屏高及字体缩放取2–4项的连续窗口，不足时只显示真实项。优先围绕当前计划时段，否则下一项，尽量保留一项前情；全部时段结束展示末尾。固定区空时保留数量、空态与新建入口。
- “查看全部”与“另有 N 项”进入所选日期的“当日日程”，只包含完整固定日程；保留原日期、返回重读，防重复打开。它不是跨日期、带阶段/Goal筛选的“全部任务”。
- 固定任务在 `[fixedStartAt, fixedStartAt + plannedDurationMinutes)` 内显示浅柑橘底、当前时段文字和计划时段进度；重叠任务分别判断，可以同时高亮。进度及“剩余”只表达计划时段，不表示执行中、完成或实际 Focus。其他项显示待到时/时段已过；时段高亮本身不写执行事实；自动 START 由业务调度器处理，时段结束不自动 END、不自动延期或失败。
- 轨道按任务顺序自然连接，不按分钟比例拉伸；首尾各收进12像素留白，单项也保留穿过节点的线。节点与时间文字行高中线对齐。没有透视倾斜、按焦点缩字或整条绿色真实时间推进线。查看上海当天且固定区非空时显示“现在 HH:mm”；每秒检查时钟，仅分钟/时段边界变动时重建，空区、隐藏和后台停止刷新，恢复时读取真实时钟，不写执行事实。
- 固定和自选任务名统一16/24，时间、时长、状态、进度说明、空态及概览标签14/20，区内查看全部/添加/展开14/20、600；星期和时区短标识12/16。概览数字20/28，页标题28/36。首页标题单行省略，完整当日日程和详情允许完整标题自然换行，存储不截断。窄屏或大字体让状态另起一行，不缩字。
- 自选默认展示前三项，超过三项才显示展开/收起，操作不重新查询。图标底36、图标22、与文字间距12，触控至少48高。今天页不再显示底部取消折叠区，取消数据保留；目标取消查询入口见下节，不把它描述为当前已接通。
- 动效统一240ms轻量尺寸/底色/计划进度过渡，系统减少动态效果时为0。安排概览统计所选日期未取消的固定数、自选数和计划分钟；尚无执行数据时不显示虚构完成数或 Focus。

以上是当前排期展示，不代替本节前述未来执行任务强调和跨日快捷栏。后续接入 START 后，计划时段标签与真实执行阶段分别呈现；当前尚未接通执行、材料、历史和目标数据，不放空回调模拟。

### 4.2 待处理与活动

以下为最终范围，当前尚未接通的入口按课程逐项实施；不以隐藏或删除取消入口作为最终不可查询方案。

- 待补材料入口查询全部日期的 EVIDENCE_PENDING，强制材料按截止时间优先，可选材料显示“无强制截止”。

- “全部任务”作为独立查询入口提供日期、阶段和 Goal 筛选，包含取消任务；History另有取消筛选。两者都可进入取消记录与再次尝试，不重新引入今天页底部取消分区。

2026-10-25 全部任务展示补正：固定时间任务直接按“开始时刻＋计划时长”排在日时间轴上，没有独立的课表任务类型或“课表／列表”选项。默认当天，可切日、选日期、回到今天；全部日期按计划日期分组并沿用相同展示。自选任务在时间轴下方，取消任务保留阅读入口但不占位。阶段／目标／以前未开始筛选收于顶栏入口，完成统计折叠。时间轴统一北京时间，跨午夜任务在所选日内裁切并标明续入／续出。冲突任务并排、斜纹只覆盖实际交集，首尾相接不冲突，多重重叠分钟取并集；被筛选隐藏的未取消任务仍参与检测，提示可查看其身份并进入原详情／执行页。短任务保持比例，并补充完整可点击阅读项。计划位置不随实际执行漂移，时段已过只作时间提示，不生成超时／完成状态。周视图和课程导入仍待后续需求。
- 下方展示最近 7 天计划数和完成数、近 30 天完成格子。两组数字分别标注，不把完成/计划强行解释为成功率。
- 日期与统计口径见[本地应用规格](本地应用规格.md#46-页面进度和日期)，没有记录显示明确空状态。

## 5. 创建、编辑与详情

新建与详情的二级页面顶栏共用AppTopBar：48圆形浅底返回按钮、24森林绿箭头、左边距24（窄屏16）、64工具栏与靠左标题，参数以[统一布局规范](../ui设计手册/颜色与布局规范.md)为准。按钮外观统一，创建页仍独立处理丢弃确认和保存期间禁止返回，详情按普通路由返回。

### 5.1 创建表单

默认 SELF_REPORT + FLEXIBLE + 今天，主区只要求标题、日期和计划时长；可展开填写 Why、具体目标、步骤与验收方向。objective 默认采用标题，用户修改过后不再跟随标题覆盖。

2026-10-23 当前创建切片：独立临时任务支持自选／固定时间，固定模式在表单内填写24小时制的小时和分钟，禁止空值、越界和不存在的当地时间；按上海排期时区转成UTC保存，并校验固定时刻属于所选日历日期。切回自选不传固定时刻，保存失败保留输入。日期在表单内展开日历，不增加选择页。当前仅接通自报完成，不显示未实现的策略下拉或方案按钮。临时任务不显示节点归属；目标树入口创建时须传真实节点并原子保存关联，编辑时读取已有归属，不能用进入页面的路径代替任务归属；节点关联尚未落地。

开启固定时间才展示时间选择；切换到可选/强制材料时展示验收方向，强制材料额外展示截止时间。修改日期/时区后重置默认截止并让用户在保存前看到最终值；若所选过去日期使默认值已经过期，标出错误，要求用户显式选择合法截止，不自动推到未来。不能在没有有效值时静默保存条件字段。

从 GoalNode 进入预填节点标题、说明与 Goal Why，归属可见。保存时重新校验 Goal 为 ACTIVE、节点有效，若已经归档或放弃，提示重新选择或改成独立任务。

保存只触发一次原子创建；失败保留用户输入，成功后在原工作上下文显示已创建并阻止重复提交，“查看今天/对应日期列表”作为可选动作，不再强制自动跳转，以满足三步交互约束。取消有内容的表单需确认丢弃。编辑、改期仅在待开始时出现，修改排期原因可选。

“再次尝试”预填来源标题、Why、方案与策略，保留 RETRY 来源；日期重置为今天、时间策略默认 FLEXIBLE，强制材料截止重算。用户必须确认保存才创建新任务，不复制事件、报告、材料或失败记录。

2026-10-23 编辑切片：当前独立自报任务的详情提供“编辑任务与排期”，共用MissionFormPage并带入原名称、具体目标、日期、计划时长和固定钟面时间；排期时区沿用原记录。只改名称或目标不新增排期，有效改期追加完整版本，旧记录保留；保存成功返回原详情，重新查询并提示“任务已更新”，返回列表刷新原日期。无改动返回不提示，有改动共用丢弃确认，失败保留输入。保存时重读任务，取消或旧快照冲突时拒绝覆盖；相同内容重试不重复写入。当前尚未开放说明、Why、步骤、验证策略/截止等其余控件与排期历史阅读入口；开始后锁定须随执行事件接入同一写事务。

### 5.2 详情主操作

2026-10-23 实现切片：详情已接通阅读、错误重试、自报任务编辑/取消，以及自报任务开始、暂停、继续、延长、结束报告和结果。END报告未完成时与FailureRecord原子保存，开始后的编辑/取消由事务拒绝。材料执行入口尚未开放。取消沿用公共确认框，失败原位提示，成功重读取消事实；返回列表仍刷新原日期，不复制顶层导航。下表仍为包含材料的完整目标能力，不能以自报切片代替材料阶段验收。

详情的中性浅底排期条显示：左侧日历图标、“固定时间／自选时间”和月日（固定时刻附 HH:mm），右侧时钟图标、“计划”和“数值 分”，中间竖线分隔。标签14/20、主要数值18/24，中性浅底上统一使用主文字色，不把排期版本号和时区标识放在此条内。固定时刻仍按记录时区换算，自选日期不作时区转换；窄屏或大字体空间不足时上下排列并使用横线分隔，不缩字或截断。此条只表达计划，不表示已经开始执行。

详情显示完整标题与阶段、排期、“为什么做”和行动方案，缺少的可选内容不制造空区块，不复制样例归属、步骤或材料。待开始的“修改任务”“取消任务”直接可见，自选任务底部“开始任务”为主操作；固定任务未到点时底部显示禁用的“到点自动开始”，到点后的待开始任务保留手动开始兜底；自报且没有验收方向时不展示空材料卡。开始后详情只读，执行页的“任务详情”入口可查看方案，再通过“返回执行任务”回到原执行页，不追加另一份执行页。正文独立滚动，底部操作避开安全区域；窄屏/大字体允许上下排列。详情不插入计时圆环或结果区。底部根据同一 Phase 查询显示操作：

| Phase | 主操作 | 次级操作 |
| --- | --- | --- |
| NOT_STARTED | 开始任务 | 编辑、改期、取消任务 |
| RUNNING | 返回执行 | 暂停、结束 |
| PAUSED | 继续执行 | 结束 |
| EVIDENCE_PENDING | 整理材料 | 可选材料可放弃提交并结束 |
| CLOSED | 查看执行记录 | 再次尝试；有材料时可修正 |
| CANCELLED | 查看取消记录 | 再次尝试 |

取消任务需要确认，开始后不显示取消入口。提前开始显示原计划时间，点击开始本身就是用户确认；如已有另一个 RUNNING，提示先暂停或结束，不静默处理它。

## 6. 执行任务

圆环和主计时显示 Focus，环内显示当前额度；增加额度后补充原计划与已增加分钟，未增加时原计划等于当前额度，不重复显示。圆环以 Current Budget 为分母，超出时保持满环并显示实际超时，不覆盖原计划。

- RUNNING 显示“暂停 / 结束”，PAUSED 显示“继续 / 结束”。
- 暂停停止增加 Focus，Elapsed 继续增加。执行中不常驻显示暂停说明；点击“暂停”后弹窗询问，可选填原因或留空，确认后保存 PAUSE 并停止计时。取消弹窗继续专注，不写 PAUSE 或 RESUME；填原因期间明确提示尚未暂停。“结束”仍沿既有流程先暂停再打开结束报告，不额外询问暂停原因。
- “延长时间”要求正整数分钟；在 PAUSED 下延长仍保持暂停。
- 达到当前额度显示“结束 / 继续”，继续选择新额度后记录 EXTEND；不自动 END，不每次刷新重复弹窗。
- 当前目标可以展开查看完整方案，开始后为只读。
- 计时器只刷新展示，时间计算遵循[领域模型](领域模型.md#6-时间口径)。窗口可见但失去输入焦点时继续更新；真正隐藏、挂起或路由被遮挡时停止重绘，恢复时立即追上真实时刻。数据重读及父组件重建不得反复重置下一秒刷新；暂停、结束后不再逐秒重绘。

执行页只保留任务身份、Focus圆环、原计划/增加额度、延长及当前目标，不重复展示详情排期条、Why和材料要求。2026-10-25 按用户新参考将“暂停/继续、结束”紧接圆环下方，延长降为文字入口，与正文一起滚动；窄屏及大字体允许按钮纵排。环内文字表达真实执行阶段，当前目标摘要可展开阅读完整方案。“结束”先暂停，成功后在本页切换成报告布局，隐藏运行圆环和执行按钮，显示冻结Focus与报告草稿，确认与取消仍固定底部。报告返回和取消不自动恢复；有输入时确认放弃草稿。

同一服务在事务成功后通知相关页面重读事实；今天的固定/自选行、全局当前任务栏、详情和历史同步状态。实时Focus从事件与当前时刻计算，只重绘可见标签，不每秒查库；暂停/结束冻结Focus。离开执行页不写PAUSE或END，返回后仍能看见运行任务并直接继续；跨日期的活动任务从全局入口找回。另一个RUNNING冲突原位显示，必须明确暂停它后再手动开始/继续当前任务，不静默切换。目标与材料文件路径仍按后续实现复核三步原则，不能将当前自报路径视为文件链路验收。

## 7. 结束确认

本节的结束确认指独立执行页内的报告状态，不要求再建一条报告路由。保留任务身份、暂停状态和冻结Focus摘要，在同一执行页切换完成情况；初次不代选，选择本身不写事实，明确确认后才保存报告与END。

从页面点击“结束”和通知点击“停止”使用同一交互：若仍 RUNNING，先保存 PAUSE，再打开完成/未完成选择；已经 PAUSED 则不重复暂停。返回或取消确认保持 PAUSED，需要明确点击继续才恢复。页面明确提示“已暂停，取消报告后仍保持暂停”。PAUSE失败不打开报告；报告期间执行序号变化时，拒绝旧确认、保留输入并要求刷新，不结束后来恢复的任务。两次提交边界见[领域规则](领域模型.md#92-结束报告的两个提交边界)。

结束报告区域展示“已完成 / 未完成”，用户确认后才写 END。选择未完成时可填原因，也可留空；按钮不得因为未填写原因而禁用。

完成时按真实策略显示：

- 自报：确认后直接结束。
- 可选材料：用户选择“直接结束 / 稍后提交材料”。
- 强制材料：显示确切截止日期和时间；如果已经过期，明确说明“仍会保存完成报告，同时记录材料未按时提交”。

确认成功后按[END 分流矩阵](领域模型.md#52-end-的分流矩阵)显示相应结果或材料工作状态。当前自报任务使用路由替换进入只读记录页，返回不重回旧执行页；保存失败保留选择和原因，不提前跳转，不产生部分END或失败记录。材料编辑时间不计入Focus；材料入口仍待后续实现。

通知授权与准时提醒能力分别查询，只有明确未允许的权限展示授权行和“去设置”；已经允许的项收起授权入口，两项均已允许时显示简洁的正常权限摘要。摘要只说明系统权限，不以权限获准代替提醒实际送达或服务健康。不能因其中一项已授权就声称整体可用；权限未知或读取失败时说明限制并允许重新读取，不保留旧的就绪结论。平台不支持的能力不展示无效开关；从对应行直接进入适用系统授权/设置，返回前台后在原页刷新，查询未完成时的再次刷新合并后重读。备份在原数据区说明范围并发起，系统保存选择返回后原位展示阶段、真实进度或未知总量状态，成功显示实际保存位置，失败保留原因和重试。“计划任务”区显示到点自动开始及执行冲突规则，默认提前10分钟提醒；点击原位底部选择关闭、开始时或5/10/15/30/60分钟，保存后重排未开始任务的提醒。关闭提前提醒不关闭自动执行和冲突提醒。关于内容原位展开。这些操作不额外导航到说明页、进度页或成功页。

- 2026-10-18新增设计硬约束：任何功能的正常完整办理路径不超过三步页面跳转，包含必经返回、自动结果跳转和系统选择器。按[三步交互原则](../ui设计手册/三步交互原则.md)审查，不将独立工作页改名弹窗来规避；早期原型分屏不等于必须拆成独立路由。相关导航仍待逐页改造和行为验收，不代表当前应用已达标。

- 中文功能文案；输入框有可见边界，聚焦、错误和禁用可辨识。
- 提交中禁用重复提交，按钮尺寸不跳变；失败保留当前表单内容。执行操作重试复用原事件编号和输入，结果不明先查保存结果；状态冲突刷新后才允许新动作，不盲目重发延长或旧报告。
- 页面可滚动，窄屏、键盘弹出、较长文件名和深层节点不溢出。
- 空状态提供一句说明和一个可执行的下一步；错误提供原因与重试。
- 数据库读取是唯一业务输入，导入 JSON 与设计稿示例不能直接当运行数据。
- 页面、系统返回和通知动作都复用领域 Workflow 和查询，不能各自维护状态。
- Windows 和 Android 的最终行为验收以[本地应用规格](本地应用规格.md)为准，当前布局图不能替代实际测试。

目标分类采用中性轨道、白色选中面、森林绿细边与文字；选中语义不只依靠颜色。由更多菜单进入已放弃后，分类栏增加明确选中的“已放弃”，保留返回进行中；放弃只改变目标状态，既有任务与历史仍按原规格保留。空态按类别展示说明，进行中仅保留一个实心创建动作，直接打开表单；导入由空态文字入口或更多菜单打开，仍在当前页预览与确认。打开导入区后不同时展示创建空态。目标空态、空日程和空历史可使用小幅透明纸艺插画，不在有内容的列表中占据持续空间，不从插画推断状态。没有填充假目标或完成率。

### 2026-10-26 颜色职责与图片

页面背景和普通信息面保持中性；森林绿用于小面积主要操作、品牌与聚焦边线；柑橘用于少量当前状态，不能成为大面积空态、通用选中填充或整页主色。正文为中性深灰，位置导航与筛选的强调低于业务主要操作。执行结束后的Focus收为28字号白底摘要，让后续材料操作优先可见。颜色、可访问配对及当前源码以[颜色规范](../ui设计手册/颜色与布局规范.md)为准。此次仅调整呈现及目标创建入口，不修改任务、事件、材料与目标状态事实。

设计哲学：尽量以语义图形、图片及表达关系和变化的动效引导，减少说明性文本；保留动作、身份、数值及必要警示。插画只在合适空态展示，有自选任务时不得用空固定区的图片挤走真实任务。新增动效单次、有限、可随系统减少动态效果关闭。宽屏目标列表与选中目录并排，侧列表收紧辅助描述；缩成单列后保留选择、导入和节点草稿。
