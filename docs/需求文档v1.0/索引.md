# Mission Book — 规格索引

## 阅读顺序

1. [产品纲领](产品纲领.md)：为什么做、长期目标与 AI 边界。
2. [本地应用规格](本地应用规格.md)：本次必须交付的闭环与验收。
3. [领域模型](领域模型.md)：术语、六个派生阶段、事件、策略、截止和原子操作。
4. [数据模型](数据模型.md)：要保存的事实，以及哪些结果只计算不重复保存。
5. [界面与交互](界面与交互.md)：当前页面、操作、返回、草稿与结果。
6. [数据落地与平台](数据落地与平台.md)：SQLite、事务、导入、附件、备份和平台要求。
7. [开发执行计划](../教学/开发执行计划.md)：先完成独立任务闭环，再逐步扩展的学习路线。
8. [UI 设计稿说明](../ui设计手册/README.md)：视觉依据及旧示意的当前替换规则。
9. [未来方向](未来方向.md)：当前明确不实现的能力；按需阅读，不提前建模。
