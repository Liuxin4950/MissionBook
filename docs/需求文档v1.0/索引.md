## 4. 使用规则

用户最新决定优先。现行规格定义目标行为，源码与验证记录说明落地程度；二者有差异时明确记录缺口，不能靠文档宣称功能已经完成。未来建议不构成用户承诺，历史限制也不阻止新需求。

核心业务规则只在领域模型定义，存储在数据模型展开。完成报告、正式材料、模型判断与用户掌握分别记录；不以计划导入、聊天回答或动画表现冒充真实行动。
