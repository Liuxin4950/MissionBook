# 上下文与工具预算

```text
发送 → 当前页面引用与任务短方案 → 长期记忆
     → 首次发送且已开启接续：最近 3 个同范围会话 → 摘要模型 → 短摘要
     → 主模型 → 按需工具 → 精简结果或显式分页详情
```

- 任务入口使用 `MissionService.findDetail` 纯读，保留目标、最多四步及验收短文。完整计划通过 `getMissionContent` 获得。首轮纯问候不发送工具定义，正常对话保留工具。
- `getSchedule` 只返回日期、分页、任务编号、标题、完整派生阶段和排期。任务索引不再逐条加载分析或重复返回引用；指定任务仍可查详细事实和分析。保持原时间规则、权限及写入事务。
- 模型设置中的「接续近期会话」默认关闭。打开后，新会话首次发送才读取同一全局、任务、节点或目标入口的最近三个会话；只向配置的摘要模型发送有界可见文字，不附工具回包、图片、文本附件、思考或已有摘要。未完成来源或摘要失败会跳过；请求并发且每项最长等待八秒。每份输出最多约 200 字；同一进程复用命中的摘要，当前会话内持久化注入块。新进程的新会话可能重新摘要；摘要调用独立于主会话的用量统计。
- 摘要不提供权限或事实；关闭接续、来源删除或更新后，在下一次发送、继续或手动压缩前撤下对应模型上下文。原始聊天仍可回放。
- 模型设置复用共享设置行。停用可恢复；删除是服务编辑草稿，保存时移出目录，不删除历史。默认/当前模型必须先切换，删除所选摘要模型时摘要改为跟随默认。历史会话用保存的模型快照展示，重新发送前需切换可用模型。
