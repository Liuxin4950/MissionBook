# 执行工具与会话提交

> 助手操作任务的批准快照、幂等核对、取消边界和会话日志投影。下列调用均已实现。

## 执行工具闭环

```text
模型 executeMission 参数
  → schema 校验 → AssistantTools.prepare 读取 MissionDetail 快照
  → 宿主权限 / 用户确认 → 固定批准参数与快照
  → _executeMission
    → END 必须有用户报告；其他动作不能携带报告
    → MissionService.prepareExecution（固定 commandId）
    → MissionService.execute → 独立 STOP 维护 → 仓储事件事务
    → 成功回执：真实事件 id、sequence、type、occurredAt、report
```

commandId 来自 ToolContext.idempotencyKey，即会话编号与调用编号的组合。提交抛错后，[工具实现](../../../../lib/application/assistant/assistant_tool_execution.dart)重读该任务事件：找到同编号则返回已保存事件；未找到且属于 ExecutionConflict / ArgumentError 时明确 ToolRejected；其他异常继续交给运行时判断结果未知。不能为重试生成新事件编号。

[工具级回归](../../../../test/application/assistant/assistant_execute_mission_test.dart)通过真实任务服务和 SQLite 验证 START、PAUSE、RESUME、EXTEND、END、缺报告零写入、提交后应答丢失找回同一事件以及预览后冲突拒绝。它与仓储时间线测试分别覆盖两个边界。

## 未执行、已执行与未知结果

```text
授权完成 → 保存 ToolExecutionStarted
  ├ 保存失败：绝不调用工具
  ├ 保存期间取消 / 期限已到：当前进程确认未调用，结算 not_executed
  └ 调用实际工具
     ├ ToolRejected：明确业务拒绝
     ├ 成功：保存实际结果
     └ 异常 / 超时 / 取消且不能确认结果：保留 unknown，要求核对
```

[AgentLoop](../../../../packages/agent_core/lib/src/agent_loop.dart)在 Started 保存后、调用前检查取消与剩余预算；超时使用调用前捕获的剩余时长。实际调用开始后不能因取消就推断未写入。

如果进程在 Started 保存后直接退出且没有结算结果，恢复过程仍保留写工具的未知状态；它无法知道退出发生在真正调用之前还是之后，不能自动重放写入。

ModelAttemptFailed 直接携带 request.purpose；会话日志按事件用途区分 conversation 与 summary，不依赖当前模型运行标志猜测。原始审计记录格式不变。

## 会话状态的提交隔离

```text
已接受 SessionState
  → copy() 创建暂存分支（共享尚未修改的集合）
  → apply(candidate) 校验序号、轮次、工具及上下文
  → 该集合首次写入时复制，原分支保持不变
  → SessionStore.append 成功 → 公布新状态
  → 校验 / 持久化失败 → 丢弃分支，停止后续操作
```

[SessionState](../../../../packages/agent_core/lib/src/sessions/session_state.dart)使用内部 CowList / CowMap / CowSet。copy 只复制固定数量的集合句柄；请求定义、用量等记录不再复制未修改的整段消息与上下文。任一分支后续写入都会分离，不要求旧分支永远不再使用。

该改动保留提交前校验和失败隔离，没有改成先污染已接受状态再回滚。新增消息首次修改的大集合仍有线性复制成本，打开会话仍重放原日志；不据此宣称长会话内存或延迟达到某个指标。见[分支隔离回归](../../../../packages/agent_core/test/session_copy_isolation_test.dart)和[运行时持久化失败回归](../../../../packages/agent_core/test/session_runtime_test.dart)。

## 展示与估算

- AssistantOperationCard 按 output 身份缓存一次解析，并把同一结果交给计数、补记摘要和详情；没有全局无限结果缓存，output 改变时重新解析。
- ApproximateTokenEstimator 仍对实际协议输入估算，图片独立计数。JSON 转义后的字符串权重使用有界缓存，最多 256 项 / 65536 个原文字符；大字符串不进入缓存，压缩试算复用旧正文时减少重复遍历。
- 权重使用十分之一 token 的整数计算，避免反复累加浮点误差。协议编码、参数校验和上下文合法性检查仍执行，输出额度与控制参数不计入输入。
- 初始化失败保留原错误，后续操作显示该错误；不继续使用泛化的“正在初始化”掩盖已知失败。

## 保留的网络边界

App 注入 publicHttpClient；URL 语法检查之后还会解析 DNS、拒绝非公网地址，并用已校验 IP 建立连接。Web 无法验证地址时明确拒绝抓取。没有依据单独的 validateUrl 判断生产客户端可访问内网，也没有为本轮修复放宽网络范围。

网络回归见 [web_service_test.dart](../../../../test/application/web_service_test.dart)。语音与关闭关系见[平台资源](../平台资源/提醒恢复与资源释放.md)，全局关系见[跨模块调用](../../调用与失败恢复关系.md)。
