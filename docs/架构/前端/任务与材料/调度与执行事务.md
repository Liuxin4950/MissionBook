# 调度、执行与任务快照

> 已实现的固定任务维护、用户命令和查询关系。阶段规则始终由完整时间线核心提供。

## 调度的两个提交边界

```text
PlannedMissionScheduler.refresh / Android 后台唤醒
  → MissionService.reconcileScheduledMissions
    → 仓储 reconcileScheduledMissions
      ① reconcileScheduledEnds：独立事务
         取得写权限 → 读取全部活动执行 → 到期逐项追加 STOP → 提交
      ② 自动 START：新的事务
         取得写权限 → 检查当前 RUNNING → 查询固定候选
         → findDetail → phase 必须为 notStarted → 复查计划窗口
         → _execute 固定身份命令 → 提交
    → changes → 页面及提醒重新读取
```

[候选 SQL](../../../../lib/data/repositories/drift_mission_repository.dart)只读取未取消、采用最新固定排期且没有 START 或 END 的任务；纯补记 END 也属于已经结束。候选再次装配后还要检查完整派生阶段。被跳过的编号会排除出本轮后续选择，避免 LIMIT 1 重复返回同一无效候选。

[事务编排](../../../../lib/data/repositories/mission_scheduling.dart)保证后一个 START 的冲突、约束错误或写入失败不会撤销先前提交的 STOP。失败仍向上抛出，调度器按既有恢复间隔重试；[MissionService](../../../../lib/application/missions/mission_service.dart)在失败分支同样发送重读通知，让已经提交的停止事实可见。

已存在 RUNNING 时不抢占；暂停任务与新开始任务的既有规则保留。START 使用计划起点，STOP 使用固定终点；晚唤醒不延长窗口，只有显式 EXTEND 改变终点。

## 连接竞争恢复

AppDatabase.transaction 按 SQLite BUSY / LOCKED 结果码有限重试尚未进入正文的 BEGIN。后台连接的 DriftRemoteException 会解包检查原异常；不解析 database is locked 等文案。正文已经运行或提交失败时不自动重放。目标包导入也使用这一入口，不再包裹整份导入做字符串重试。

## 用户命令与报告

MissionService.execute 和 reportExecution 仍先独立结算到期 STOP，再执行命令事务。命令内重读预期序号和排期，报告、必要 END 与失败事实原子保存。旧快照被拒绝后，已经保存的 STOP 保留为 reportPending。

固定命令身份用于幂等：已保存事件先于新状态校验识别；同一次请求的响应丢失不生成第二条执行事件。助手工具的上层核对见[执行工具与会话提交](../助手与总结/执行工具与会话提交.md)。

## 编辑和材料关联

- 排期 changedAt 记录提案准备时刻；任务及方案 updatedAt 由取得写权限后的仓储时钟决定。时钟回拨时不早于已提交任务版本。二者不要求相等，旧表单仍由版本及字段校验拒绝。
- 材料关联命令的回执用于确认既有提交。回执确认到重新读取之间若任务被维护删除，抛出明确 EvidenceConflict；不重新捕获来源，也不使用空断言。
- 报告查询统一按 reportedAt、id 排序。有效报告与后续更正都以 supersedesId 替代链尾项确定；时钟回拨后不把最大时间戳的旧声明重新选为最新，排序不代替业务有效性。

## 不可变详情

[MissionDetail](../../../../lib/domain/entities/mission_detail.dart)防御性复制完整事件、失败、材料和用户报告列表，并在构造时调用 deriveMissionPhase。查询 Future 在装配阶段就会报告坏事实；同一快照的排序、列表和详情读取复用已经计算的结果。

effectiveEvidence 和 effectiveUserReport 只在同一不可变快照中计算一次。phase 仍是只读派生结果，调用方不能传入阶段，数据库没有新增 phase 字段。新查询返回新快照，不能原地追加事件后要求旧快照更新。

执行 Focus、暂停、预算和超时继续由 [execution_time_rules.dart](../../../../lib/domain/rules/execution_time_rules.dart)计算。设备历史日期、用户报告日和排期时区未合并。

## 页面读取关系

目标目录 active=false 时停止新查询，首次未激活或依赖替换也有空任务 Future；激活后读取当前依赖。按父节点一次建立兄弟集合、有效位置与数量，节点行不再重复扫描全部节点；连接线只在 guides、expanded 或 step 改变时重绘。执行草稿位于独立页面，已移除恒真的折叠确认钩子。

全部任务页的打开保护只覆盖派发过程，右栏存续期间左侧仍可选择另一任务。执行页沿用页面注入的 clock；详情关闭会刷新。周表日详情弹层返回旧编号时，当前列表若已不存在该任务则提示重选，避免 firstWhere 抛错。
