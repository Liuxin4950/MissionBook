## 相机状态流

```text
启动 / 恢复 → 申请设备与初始化 → 取景 → 拍照 → 保存草稿
                                      └ 保存失败 → 保留同一照片 → 重试保存 / 重拍
暂停 / 离开 → generation 失效 + 释放控制器 → 迟到拍照结果丢弃
```

保存进行中用独立确认标记阻止重复加入；后台释放取景控制器不解锁正在保存的照片。全屏自动确认失败也保留照片和重试操作。权限拒绝、受限与不再询问均给中文提示，可重试。

## 语音状态流

```text
prepare → 共享 _preparing → spawn + 有界握手 → worker 初始化 → ready
transcribe → 请求身份 + 超时 → 识别结果
超时 / worker 退出 → 拒绝未完成请求 + 释放端口 → 下次 prepare 重建
任何阶段 dispose → generation 失效 + 幂等关闭 → 迟到 worker 不复活
```

启动、识别和关闭各有超时边界。并发 prepare 只初始化一次；测试注入 workerMain 验证协议，生产仍使用真实 FFI worker。

## 验证边界

[相机测试](../../../../test/presentation/evidence_camera_panel_test.dart)使用官方 CameraPlatform 替身，覆盖权限、控制器释放、后台迟到结果及保留照片重试。[语音测试](../../../../test/data/speech/sherpa_speech_engine_test.dart)使用真实 isolate 和协议替身，覆盖并发初始化、无握手、崩溃、超时及关闭重建。

这些测试未加载真实模型和摄像头。真实麦克风、人声识别、FFI 兼容、系统权限弹窗、通知后台唤醒及设备照片质量仍需目标设备验证。
