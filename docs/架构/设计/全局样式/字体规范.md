# 字体规范

> 2026-11-02 更新。所有数值是逻辑字号，继续使用系统文字缩放；文字角色定义在 [app_typography.dart](../../../../lib/core/theme/app_typography.dart)，组件默认值在 [app_theme.dart](../../../../lib/core/theme/app_theme.dart)。

## 文字角色

| 用途 | Theme 角色 | 字号 / 行高 | 字重 |
| --- | --- | --- | --- |
| 页面主体标题、详情任务身份 | headlineSmall（其余 headline 同档） | 20 / 28 | 600 |
| 弹窗、弹层标题 | titleLarge | 16 / 24 | 600 |
| 顶栏、区块标题、普通统计主值 | titleMedium | 14 / 20 | 600 |
| 任务、目标、节点、设置列表项与表单标签 | titleSmall | 12 / 16 | 500 |
| 记录、聊天、摘要长正文及输入值 | bodyLarge | 14 / 20 | 400 |
| 日期、时长、阶段、数量、归属、说明 | bodyMedium / bodySmall | 12 / 16 | 400 |
| 填充式主要操作 | labelLarge | 14 / 20 | 600 |
| 文字/描边操作、筛选、分段、底部导航 | labelMedium / labelSmall | 12 / 16 | 500 |
| 执行页主计时 | displaySmall（其余 display 同档） | 48 / 56 | 500 |

启动页品牌字单独保留 34 / 30 两档，不进入普通内容页。所有 Material 档位均显式映射，避免缺省大字意外进入页面。

## 组件约束

- 列表标题、统计值不能借用弹窗标题或页面大标题。安排概览主值为 14，说明为 12；任务名为 12，区块标题为 14。
- 默认 ListTile 标题/副标题为 12；AppSettingsRow 也使用同档标题。普通文字与描边按钮为 12，主要填充按钮为 14。
- 输入框值保持 14；标签、提示状态为 12，输入提示继承输入值样式。用户内容和生成的长正文明确选 bodyLarge，不能依赖默认 bodyMedium。
- 下拉及弹出菜单选项为 12；表单当前值保持 14。Material 3 菜单显式使用 labelTextStyle，避免回退到 labelLarge；带选中态的选项复用 AppSelectionOption。
- 列表页的紧凑筛选选择器使用 bodySmall（12）呈现当前条件，与筛选及次要操作同档；模型配置等编辑表单当前值仍为 14。
- Markdown 正文为 14，一级标题为 16，其余标题为 14；代码为 12。列表标记与正文使用相同阅读字号。
- 思考及处理中间说明使用紧凑 Markdown：正文、标题及列表为次级 12，块间距为 spaceXs，不抬升为回答标题；最终回答仍使用普通阅读规范。
- 页面不写 fontSize；需要强调时选择角色、字重或语义色，不通过 copyWith 修改字号。
- 缩小可视文字不缩小点击范围。按钮保留至少 48 的触控范围，主要操作最小高度为 52。
- 不固定 TextScaler，也不根据桌面/手机擅自放大文字。布局按可用宽度和实际字号换行、滚动或切换列数，不能裁字来凑同高。

## 本轮落地与验收范围

中央主题覆盖全部使用 Theme 的页面；针对安排概览、目标/节点、历史任务、助手计划任务、执行记录统计、空态和共享设置行修正了角色误用。记录详情、摘要与用户聊天正文明确使用阅读角色。
