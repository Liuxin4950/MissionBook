## 视觉角色

| 类别 | 当前值 / 用途 |
| --- | --- |
| 表面 | background #F7F8F5，card #FFFFFF；普通控件用 surfaceMuted |
| 品牌 | primary #244D3D，主要操作和选中项；accent #D9F28B 仅小面积状态强调 |
| 文字 | textPrimary #282E2A，textSecondary #626A64 |
| 反馈 | error/errorSoft、warning/warningSoft；相机使用 mediaBackground/onMedia |
| 字号 | 页面标题 20、弹窗标题 16、区块及统计主值 14、列表及辅助信息 12、密集周表星期/日期 11、阅读正文及输入 14；执行主计时 48。见[字体规范](字体规范.md) |
| 间距 | spaceXs/Sm/Md/Lg/Xl/Xxl/3Xl = 4/8/12/16/20/24/32；sectionGap 和 paneGap 统一为 16 |
| 圆角 | 4/8/12/16/20/24，胶囊为 radiusPill；按组件角色选取 |
| 操作 | 最小触控 48，主要操作最小高度 52；图标视觉尺寸不代替触控区域 |

跨区块及双栏间距统一用 16；区块内部按内容层级用 4/8/12/16。对话框、底部弹层和卡片保留各自的内边距，空态留白与 48 触控尺寸不随区块间距调整。组件自身的缩略图尺寸、相机比例和侧栏内容宽度可以有局部常量。不要把碰巧数值相同的 topBarHeight 当作图片尺寸；结构间距与相同用途的操作高度优先使用 token。

当前产品只实现浅色主题；`MaterialApp` 显式使用 `ThemeMode.light`，系统暗色模式不会切换配色。

## 布局与状态流

```text
窗口宽度 → compact (<600) / medium (600–839) / expanded (>=840)
  → 主导航形态
内容区实际宽度（扣除导航与边距）→ 是否满足左右栏最小宽 → 单栏或双栏
组件当前状态 → 加载 / 内容 / 空态 / 失败及重试
```

扩展导航阈值为 1200。双栏按内容宽度 480 + 24 + 360 判断，不能仅凭整个窗口进入 expanded 就强制分栏。表单两列按自身面板 560 判断；详情阅读区与仪表盘分别限宽。

quick/standard/navigation/exit/entrance/launch 为 180/240/280/200/420/450ms。组件通过 AppMotion.resolve 响应减少动效，弹层、对话框与 PopupMenuButton 使用 AppMotion.overlayStyle 显式配置进入和退出。

## 动效管理

设置保留跟随系统、开启动效、减少动效三档，新增页面切换的跟随平台、淡入、轻滑动。强度弹层提供共享展开、分段控件、颜色和进度的实际预览。页面风格弹层内嵌真实 Navigator，用不同底色和图形区分列表与详情，选风格后自动预览，并提供重播和返回。减少动效时明确显示当前状态。本机强度与风格保存于原 page_motion.txt / Web localStorage 键的 JSON，旧枚举字符串仍能读取，未知风格回退平台。保存成功后才更新界面，失败保留原值并允许重试。

MotionSettingsHost 将偏好应用于 MediaQuery、路由主题、按钮反馈与 ExpansionTile。普通及嵌套 MaterialPageRoute 共用主题，平台风格沿用平台时长，自定义风格使用 280/200ms。自定义转场保留平台手势检测，交互返回时由平台渲染。减少动效时路由和已接入弹层零时长，组件直接收敛到目标状态。尺寸变化统一使用 AppAnimatedSize，减少动效时直接布局，避开框架零时长 AnimatedSize 的布局重入，切换策略时通过同一子树保留输入状态。

主导航在 IndexedStack 外使用 AppContentTransition 短淡入，保持页面身份、滚动和输入状态，隐藏页面继续由 TickerMode 暂停。节点展开、分段选中、今天页状态切换沿用现有 AppMotion 接入，目标列表与详情的共享进度对真实比例变化补间，首次加载直接显示实际比例。业务保存、返回值和草稿守卫由原调用方掌控。

启动动效使用宿主内的 context，减少动效时跳过品牌等待。Android 原生悬浮菜单读取相同设置文件，正常时短淡入，减少动效时直接显示，移除时取消动画。系统键盘、权限及截屏选择器由系统控制。DropdownButtonFormField 内部菜单沿用框架实现，其动画尚未显式接入本机策略。AI 流式滚动仍使用现有跟随条件，性能需真机 profile 单独采样。

动效与页面切换共用 MotionSettingsPanel。两个设置入口均采用标题在左、当前值和箭头在右的单行排布，弹层均采用顶部标题与重播、中部圆角预览、底部选项及右侧勾选，状态和错误提示位置一致。预览高度由实际内容决定。

## 交互与约束

菜单选项统一使用 12 的说明字号；Material 3 通过 PopupMenuThemeData.labelTextStyle 覆盖默认 labelLarge，textStyle 仅作为其他菜单实现的补充。表单下拉和快捷选择菜单复用 AppSelectionOption：白色菜单、内缩圆角浅绿选中项、右侧 18 勾选，最小触控高度 48；输入框当前值仍为 14。禁用的填充按钮统一使用 disabled / onDisabled，避免同一工具栏混用不同灰色。

助手输入区图标统一为 20，操作与上下文指示的占位为 48；思考快捷菜单使用窄版竖排列表，内容宽度默认 128、外层留白 4，单项最小触控高度 48，选项只保留档位名称；菜单按实际字号增加宽度并受视口限制。加号菜单只提供附件操作。回复支持长按选区复制，整条回复复制入口保留。上下文预算环点按或长按都打开同一主题化底部面板，不弹出大块纯文本预览；底板、预算进度和状态颜色使用当前 ColorScheme 及警告颜色令牌。面板标题使用 titleLarge（16），分区标题 titleMedium（14），统计行 bodySmall / labelMedium（12）；手动压缩和用量范围提示保留，长说明保持精简。助手设置的测试连接和结果归入模型卡片，底部只保留保存；权限说明按语义短句在实际宽度不足时换行，备份标题与操作在满足文字缩放后的宽度时并排。

助手普通写操作的完成/取消结果默认使用一行摘要，文字为 12、图标为 18、整行触控最小 48，边框使用 hairline、圆角 radiusMd。名称过长在摘要内省略，展开后可读完整输入、对象入口与回执；详情行不再占据收起状态。确认、失败和未知结果仍保持处理入口可见。

助手思考不放入回答卡片：同一输入的思考与操作归入一个处理过程，完成后默认收起，回答正文独立。思考行使用无边框次级 12 号文字、单行预览和 18 图标，完整思考以紧凑 Markdown 展开。整个过程只保留一个收起入口，过程和思考不设内部纵向视口，确认/失败/未知操作默认展开且不裁掉处理入口。

记录删除使用共享 AppConfirmDialog；错误态给出操作级中文原因和重试入口，不能把读取失败显示成“没有记录”。图片读取和解码失败均有可见状态，列表缩略图的 Future 缓存于对应状态对象，重建列表不重复读取。

目标/节点标题可展开时使用有焦点与键盘反馈的 InkWell，并保留按钮语义；说明文字不额外覆盖隐形点击区。记录滑动删除保留读屏自定义操作。

节点路径优先展示名称、任务状态与维护操作；节点摘要只从三点菜单打开自适应弹层，不占节点列表正文。目标/节点记录入口按实际归属查询，显示真实数量；零条隐藏，失败显示重试，不能混为无记录。

目标路径搜索使用全局 14 号输入及 12 号提示，保留共享输入框配色与 radiusMd 圆角；isDense 配合 spaceSm 竖向内边距，输入及清除按钮保留 48dp 触控，描边表面上下各内收 spaceSm，常规可见高度 32dp，较大系统字号自然增高；显式使用 TextAlignVertical.center 与 alignLabelWithHint=false，使输入、提示、光标和图标居中，不沿用表单的顶部对齐。节点短状态收在标题下，数量及展开箭头独立占用 48dp 触控区；根节点常规高度含内外间距约 60dp。目标卡与节点卡的 Material、整卡 InkWell 共用圆角和边界，按压底色覆盖完整表面和目标进度区。

目标列表的目录面板省去“行动路径”标题行；新增节点加号位于当前展开目标的数字进度行最右侧，保持 48dp 触控。

目标进度使用加长细条与浅绿 x/y 数字胶囊，去掉可见的“完成节点”说明；数字使用 labelMedium、primary 与 radiusPill，条形占据胶囊和新增按钮之外的剩余宽度。完整完成口径保留在 Semantics 标签。

目标页采用紧凑目录：目标卡标题与节点名称使用 titleSmall（12），状态、任务数量、日期和进度使用 bodySmall（12），详情标题使用 titleMedium（14）。目标进度只把“至少有一项直接任务，且全部直接任务均报告完成”的有效节点计入完成数；无直接任务的节点不计完成。节点行的“有完成记录”及记录图标仍表示存在任意一项 END(COMPLETED)，不代表整个节点完成。路径面板内边距使用 spaceSm，节点内容自然增高，图标操作保持 48 最小触控区域，不缩放系统字号。节点数量和维护菜单同行，内容区不足 360dp 时通过原菜单建任务，宽面板保留加号；展开内容只留两侧 spaceSm，通过浅色任务表面和外层节点缩进表达归属；操作关系见[任务与材料](../../前端/任务与材料/README.md)。

节点标题触控区至少 48 高，手机可直接点标题展开/收起子节点；左侧箭头保留同一操作，节点右侧数量及箭头独立展开本节点任务，叶节点标题也可展开任务或记录。没有直接任务时隐藏状态文字和任务展开箭头，添加和维护操作保留在菜单或宽面板标题行；有任务时按全量完成或部分完成显示状态。收起时标题单行省略，展开后显示完整名称。任务卡片、分页与记录入口共用两侧 8dp 内边距，移除原先避让节点标记的 60dp 空白；不在任务列表前重复铺开节点说明，说明继续保存在节点编辑及摘要数据中。目标直属任务保持原宽度。

记录列表使用统一白色内容卡与页面边距，正文优先，时间和归属为辅助信息，不在列表铺开模型配置状态。阅读外框最大 1080，内宽满足 `680 × 文字缩放` 时双列，否则单列；卡片随文字自然增高，空态和单页不显示分页。记录详情保持 792 阅读限宽：发生时间和归属用辅助字号紧凑呈现，正文与附件为主体；编辑放在顶栏图标操作，归属维护进入更多菜单，任务材料入口仅在尚未提交时显示，不展示冗余保存时间和原始附件文件名。

执行历史的筛选栏到首个日期标题使用 spaceMd（12），日期标题到卡片、同组卡片之间使用 spaceSm（8），前组卡片到下组日期标题合计 spaceLg（16）。列表只保留一层卡片外间距，不叠加页面底部留白；卡片内部信息、缩略图和触控区域保持原有规则。

任务详情使用共享内容卡呈现排期、说明及行动方案；排期日期和时长使用 bodyMedium（12），行动步骤使用 titleSmall（12），任务名称保持 headlineSmall（20），区块标题使用 titleMedium（14），主要操作保持 labelLarge（14）。只有默认同名正文且没有步骤时省略重复方案区块。执行记录展示结果、实际发生日期/时段、应用计时、材料及时间线；补记不展示伪造的零值计时统计。计时明细默认收起，时间更正及任务评价进入顶栏菜单，再次尝试为正文末尾的次要操作。摘要生成按钮放在展开内容内。

未开始任务详情的底部主操作独占一行，修改与取消使用等宽双按钮行，不因扣除页面边距后不足 320 而改成纵排。按钮继承全局 OutlinedButton 主题、最小触控尺寸及共享间距；大字号和长文案可在按钮内部居中换行。

本轮验证包括窄屏、大字号、共享按钮及失败恢复的 Widget 回归；未以旧设计截图或测试通过替代当前目标设备的视觉与手势验收。业务流程见[任务与材料](../../前端/任务与材料/README.md)。

AI 日记本复用 AppEmptyState 与 AppIllustration：初始空态使用纸质日记本插画、短提示和一个主要添加按钮，已有查询结果时显示数量与顶栏新增入口。搜索与过期筛选保留，搜索无结果提供清除搜索，空分页提供返回上一页；宽内容区可横排，字号放大时退回纵排并允许页面滚动。插画为装饰，操作名称仍由原生按钮向辅助技术提供。

日记本搜索区按正文可用宽度达到 `600 × 字号缩放` 时并排，否则分行；数量与筛选在窄屏可换行。页面使用 CustomScrollView，SliverLayoutBuilder 扣除搜索与状态区实际高度后，让空态在剩余视口居中；内容超出时正常滚动，避免短屏固定高度裁切主按钮。

日记本主添加按钮使用 actionMinHeight（52）最小高度，仍继承全局 FilledButton 颜色、文字、圆角与交互反馈；工具栏复用 mediumBreakpoint（600），按正文宽度和字号判断并排条件，不借用表单双列阈值。

今日日程使用 spaceMd 分区内边距、spaceSm 任务上下内边距。今天页任务标题与小操作统一使用 labelSmall（12、500 字重），区块标题使用 labelLarge（14）；安排概览的数值和说明统一使用 12。状态与导航箭头置于任务首行右侧，下一行左侧为时间和计划时长，右侧为真实专注计时，左右各自可自然换行。时区另起辅助行。首页标题最多两行，完整日程自然展开。当前时段的细进度条和剩余分钟同行，状态不额外套带内边距的标签。数量与当前时间归入区块标题区域，整行点击与统一读屏动作保持一致；不固定任务高度，不缩放系统字号。

共享 AppSectionCard 默认水平内边距保持 spaceXl（20），上下改为 spaceMd（12）；今天页的自选时间和安排概览同步收紧上下内边距。文字缩小不降低按钮的最小触控高度，不修改系统文字缩放。

日程右侧的执行时长省略重复的“专注”前缀，继续使用 MissionLiveStatus 事件计算。自选时间区的水平内边距使用 spaceMd（12），添加按钮水平内边距使用 spaceSm（8），避免两层留白堆叠。

全部任务使用七列等宽周表，保留窄时间栏，手机正文两侧各 spaceSm，宽屏各 spaceXxl；列宽只由实际面板宽度决定，不横向滚动。标题沿用 labelSmall（12），允许换行，窄列只展示标题，宽列补充时段和状态；完整信息通过日期弹层和原详情入口阅读。任务条使用 radiusXs，固定计划按名称稳定使用全局 scheduleMint、scheduleBlue、scheduleLilac、scheduleOlive 配色及相应侧边色；实际执行保留 warningSoft，冲突侧边保留 error。任务颜色只区分名称，不代表阶段。今天列使用低透明 primarySoft。星期与日期使用 calendarLabel（11 / 14），星期/日期间隔 2，日期底色最小宽 24（受列宽限制）、上下留白 3；日期头上下留白 4，仍保留至少 48 的点击高度。周表卡上下留白 4，手机页上下留白 12，周导航与周表间隔 8。日期底色保留水平留白，避免紧贴数字。纵向由页面统一滚动，不压缩系统字号，不提供额外的周时间表/周列表 tabs。

## 界面文案与信息密度

页面优先显示用户当前需要的状态和操作。标题、摘要和操作行不重复表达同一事实；正常状态不附带通用提示。说明只保留影响当前选择、权限或结果的关键信息，复杂细节按需查看。文案按实际宽度与系统字号适配，不靠截断或缩小字体掩盖冗长内容。

提醒与权限区将待处理状态直接放在对应操作行，多个缺失权限分别提供入口；执行通知和超级岛状态使用简短文字。未知、失败和平台限制仍明确显示。
