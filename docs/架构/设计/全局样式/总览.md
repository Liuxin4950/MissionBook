## 视觉角色

| 类别 | 当前值 / 用途 |
| --- | --- |
| 表面 | background #F7F8F5，card #FFFFFF；普通控件用 surfaceMuted |
| 品牌 | primary #244D3D，主要操作和选中项；accent #D9F28B 仅小面积状态强调 |
| 文字 | textPrimary #282E2A，textSecondary #626A64 |
| 反馈 | error/errorSoft、warning/warningSoft；相机使用 mediaBackground/onMedia |
| 字号 | 页面标题 20、弹窗标题 16、区块及统计主值 14、列表及辅助信息 12、阅读正文及输入 14；执行主计时 48。见[字体规范](字体规范.md) |
| 间距 | spaceXs/Sm/Md/Lg/Xl/Xxl/3Xl = 4/8/12/16/20/24/32 |
| 圆角 | 4/8/12/16/20/24，胶囊为 radiusPill；按组件角色选取 |
| 操作 | 最小触控 48，主要操作最小高度 52；图标视觉尺寸不代替触控区域 |

组件自身的缩略图尺寸、相机比例和侧栏内容宽度可以有局部常量。不要把碰巧数值相同的 topBarHeight 当作图片尺寸；结构间距与相同用途的操作高度优先使用 token。

## 布局与状态流

```text
窗口宽度 → compact (<600) / medium (600–839) / expanded (>=840)
  → 主导航形态
内容区实际宽度（扣除导航与边距）→ 是否满足左右栏最小宽 → 单栏或双栏
组件当前状态 → 加载 / 内容 / 空态 / 失败及重试
```

扩展导航阈值为 1200。双栏按内容宽度 480 + 24 + 360 判断，不能仅凭整个窗口进入 expanded 就强制分栏。表单两列按自身面板 560 判断；详情阅读区与仪表盘分别限宽。

quick/standard/entrance/launch 为 180/240/420/450ms，页面动效通过 AppMotion.resolve 响应减少动效。弹层、确认与返回继续复用已有导航机制。

## 交互与约束

菜单选项统一使用 12 的说明字号；Material 3 通过 PopupMenuThemeData.labelTextStyle 覆盖默认 labelLarge，textStyle 仅作为其他菜单实现的补充。表单下拉和快捷选择菜单复用 AppSelectionOption：白色菜单、内缩圆角浅绿选中项、右侧 18 勾选，最小触控高度 48；输入框当前值仍为 14。禁用的填充按钮统一使用 disabled / onDisabled，避免同一工具栏混用不同灰色。

助手输入区图标统一为 20，操作与上下文指示的占位为 48；思考快捷菜单使用两行四格，内容宽度默认 160、外层留白 4，单项最小触控高度 48，选项只保留档位名称；菜单按实际字号增加宽度并受视口限制。助手设置的测试连接和结果归入模型卡片，底部只保留保存；权限说明按语义短句在实际宽度不足时换行，备份标题与操作在满足文字缩放后的宽度时并排。

助手普通写操作的完成/取消结果默认使用一行摘要，文字为 12、图标为 18、整行触控最小 48，边框使用 hairline、圆角 radiusMd。名称过长在摘要内省略，展开后可读完整输入、对象入口与回执；详情行不再占据收起状态。确认、失败和未知结果仍保持处理入口可见。

助手思考不放入回答卡片：同一输入的思考与操作归入一个处理过程，完成后默认收起，回答正文独立。思考行使用无边框次级 12 号文字、单行预览和 18 图标，完整思考以紧凑 Markdown 展开。整个过程只保留一个收起入口，普通生成过程高度受视口约束并可滚动，确认/失败/未知操作默认展开且不裁掉处理入口。

记录删除使用共享 AppConfirmDialog；错误态给出操作级中文原因和重试入口，不能把读取失败显示成“没有记录”。图片读取和解码失败均有可见状态，列表缩略图的 Future 缓存于对应状态对象，重建列表不重复读取。

目标/节点标题可展开时使用有焦点与键盘反馈的 InkWell，并保留按钮语义；说明文字不额外覆盖隐形点击区。记录滑动删除保留读屏自定义操作。

节点路径优先展示名称、任务状态与维护操作；节点摘要只从三点菜单打开自适应弹层，不占节点列表正文。目标/节点记录入口按实际归属查询，显示真实数量；零条隐藏，失败显示重试，不能混为无记录。

目标页采用紧凑目录：目标卡标题与节点名称使用 titleSmall（12），状态、任务数量、日期和覆盖率使用 bodySmall（12），详情标题使用 titleMedium（14）。卡片不铺开目标说明，也不再增加整行目录按钮；进度与完成节点计数合为一行。路径面板内边距使用 spaceSm，节点内容自然增高，图标操作保持 48 最小触控区域，不缩放系统字号。节点加号和维护菜单同行，任务展开后占满节点内容宽度，整行可点击；操作关系见[任务与材料](../../前端/任务与材料/总览.md)。

节点标题独占正文首行，收起时单行省略，展开后显示完整名称。第二行的状态与展开提示靠左，新建和维护菜单靠右，两组共用正文宽度，不再让图标列同时挤压标题和状态；大字号仍允许自然增高。

记录列表使用统一白色内容卡与页面边距，正文优先，时间和归属为辅助信息，不在列表铺开模型配置状态。阅读外框最大 1080，内宽满足 `680 × 文字缩放` 时双列，否则单列；卡片随文字自然增高，空态和单页不显示分页。记录详情保持 792 阅读限宽。

任务详情使用共享内容卡呈现排期、说明及行动方案；只有默认同名正文且没有步骤时省略重复方案区块。执行记录展示结果、实际发生日期/时段、应用计时、材料及时间线；补记不展示伪造的零值计时统计。计时明细默认收起，时间更正及任务评价进入顶栏菜单，再次尝试为正文末尾的次要操作。摘要生成按钮放在展开内容内。

未开始任务详情的底部主操作独占一行，修改与取消使用等宽双按钮行，不因扣除页面边距后不足 320 而改成纵排。按钮继承全局 OutlinedButton 主题、最小触控尺寸及共享间距；大字号和长文案可在按钮内部居中换行。

本轮验证包括窄屏、大字号、共享按钮及失败恢复的 Widget 回归；未以旧设计截图或测试通过替代当前目标设备的视觉与手势验收。业务流程见[任务与材料](../../前端/任务与材料/总览.md)。

AI 日记本复用 AppEmptyState 与 AppIllustration：初始空态使用纸质日记本插画、短提示和一个主要添加按钮，已有查询结果时显示数量与顶栏新增入口。搜索与过期筛选保留，搜索无结果提供清除搜索，空分页提供返回上一页；宽内容区可横排，字号放大时退回纵排并允许页面滚动。插画为装饰，操作名称仍由原生按钮向辅助技术提供。

日记本搜索区按正文可用宽度达到 `600 × 字号缩放` 时并排，否则分行；数量与筛选在窄屏可换行。页面使用 CustomScrollView，SliverLayoutBuilder 扣除搜索与状态区实际高度后，让空态在剩余视口居中；内容超出时正常滚动，避免短屏固定高度裁切主按钮。

日记本主添加按钮使用 actionMinHeight（52）最小高度，仍继承全局 FilledButton 颜色、文字、圆角与交互反馈；工具栏复用 mediumBreakpoint（600），按正文宽度和字号判断并排条件，不借用表单双列阈值。

今日日程使用 spaceMd 分区内边距、spaceSm 任务上下内边距。今天页任务标题与小操作统一使用 labelSmall（12），区块标题使用 labelLarge（14）；状态与导航箭头置于任务首行右侧，下一行左侧为时间和计划时长，右侧为真实专注计时，左右各自可自然换行。时区另起辅助行。首页标题最多两行，完整日程自然展开。当前时段的细进度条和剩余分钟同行，状态不额外套带内边距的标签。数量与当前时间归入区块标题区域，整行点击与统一读屏动作保持一致；不固定任务高度，不缩放系统字号。

共享 AppSectionCard 默认水平内边距保持 spaceXl（20），上下改为 spaceMd（12）；今天页的自选时间和安排概览同步收紧上下内边距。文字缩小不降低按钮的最小触控高度，不修改系统文字缩放。

日程右侧的执行时长省略重复的“专注”前缀，继续使用 MissionLiveStatus 事件计算。自选时间区的水平内边距使用 spaceMd（12），添加按钮水平内边距使用 spaceSm（8），避免两层留白堆叠。

全部任务的日期快捷项、阶段筛选及小操作使用 labelSmall（12），筛选及时间安排标题使用 labelLarge（14）。任务时间区域默认按视口高度自动缩小分钟比例，刻度同步减少；保留文字缩放及宽度不足时的横向滚动，短时段提供紧凑列表切换入口。

全部任务的日期范围、阶段和目标归属使用 AppDropdownFormField，不再铺开阶段标签；紧凑筛选值为 12，菜单沿用共享选中态与圆角。今天、全部日期和以前未开始统一进入日期范围，顶部日期导航不额外铺快捷按钮。日期与阶段按面板宽度和字号决定一列或两列，目标选择保持整行。

当日日程使用共享 AppSegmentedControl 切换“日程列表 / 时间轴”，默认列表；时间轴与全部任务共用 MissionTimetable 的颜色、字号、比例压缩和冲突提示，隐藏图内重复切换按钮。新增模式栏占位计入可用图表高度，手机、平板和桌面按正文宽度及实际文字缩放布局，不增加新字体或配色。
