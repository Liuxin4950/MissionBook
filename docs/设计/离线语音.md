# 离线语音识别（SenseVoice）

App 内语音不再依赖手机厂商的识别 UI、默认服务或转写 API Key。主界面语音用 `record` 采集后交给 Dart 语音后端，Android 悬浮入口用原生 `AudioRecord` 面板采集，两者共用同一份识别路由。本轮（2026-11-23）把悬浮入口改成票据化调用链，协议冻结在[悬浮语音通道契约](悬浮语音通道契约.md)。

## 结论与边界

- 默认离线：没有显式选择转写服务时一律走端侧 SenseVoice，`sherpa-onnx` 与 Android 原生包统一为 1.13.8，模型 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`（int8，约 230 MB）。旧文档的 1.12.21 已更正。
- 显式远程：只有用户自己保存了「录音转写服务」（endpoint/model 与独立凭据 `MISSIONBOOK_TRANSCRIPTION_API_KEY`）时才上传音频；不读主模型 Key，也不把凭据下发原生。
- 失败不静默切换：离线模型缺失/损坏/加载失败、远程配置缺失/无效都按错误码明确回报，不偷偷换到另一条后端重试。
- 不自动发送：转写文字只追加到发起时的草稿（保留原草稿，换行拼接），是否发送由用户决定。
- 模型缺失不下载、不申请麦克风：预检失败时原生停在错误态并给出「打开语音设置」，下载只由设置页的独立操作触发。来源、版本与校验值见[模型说明](../../assets/models/sensevoice/README.md)。
- 采集格式：主界面 `record`、悬浮面板 `AudioRecord` 都是 16 kHz 单声道 PCM16、最长 30 秒（≈960000 字节）；原生不判断模型目录、不读安全存储、不持有转写 Key。
- 当前平台：Android 可用。Windows 端 `sherpa_onnx` 的 Windows 预编译包与自带 ONNX Runtime 版本不匹配（DLL 请求 API 28，运行时仅 1.17.1），本轮不启用本地引擎；Windows 和浏览器仍可使用已有的录音转写服务，或文字输入。

## 悬浮语音调用链（2026-11-23 现行）

```text
悬浮动作球「语音」→ AssistantOverlayService.openVoice()：生成 UUID 票据 → 启动录音面板
  AssistantOverlayVoiceActivity
    → beginVoice{ticket, generation}
        AssistantWorkspaceBridge → AssistantVoiceChannel.begin
          → assistant.prepareExternalEntry() → speech.preflight()
             ├ 离线：只校验并 prepare 已安装的 SenseVoice（不下载、不联网、不申请麦克风）
             └ 远程：只校验已保存的 endpoint/model 与独立凭据（不上传音频）
        ← {ready, mode, draftKey, label} | {ready:false, mode, errorCode, message}
    → 只有 ready=true 才申请麦克风；AudioRecord 录 16 kHz 单声道 PCM16（≤30 s）
    → voice{ticket, pcm}
        AssistantVoiceChannel.voice → 用本轮固定的后端转写 → 追加到票据绑定的草稿
        ← {accepted:true, draftKey} | {accepted:false, errorCode, message}
    → AssistantOverlayService.voiceDone(ticket, draftKey)：校验票据后回到该草稿，不发送
    → 关闭 / 返回 / onPause / 超时 / 工作区切换：cancelVoice（幂等）
```

- 方法名、payload、错误码与状态映射的唯一来源是[悬浮语音通道契约](悬浮语音通道契约.md)；改协议先改契约，再由原生与 Dart 两侧同步。
- 一次悬浮录音只有一个票据：准备、录音、转写任一阶段的重复提交只能拿到 `ticketInvalid`；`cancelVoice` 对不存在的票据也返回成功。
- 票据绑定草稿与识别方式，中途改设置不会切换本轮后端；草稿被切换或工作区代次变化时放弃写回，不把文字写到别的草稿。
- 转写成功后原生以 `ticket + draftKey` 调用 `voiceDone`，由悬浮服务校验票据确实是它发出的那一个，再打开同一草稿的对话输入区。
- 失败态额外提供「打开语音设置」：原生以一次性路由 `assistant_route=voiceSettings` 启动 `MainActivity`，Flutter 外壳取走路由后打开现有助手设置并定位到「语音输入」分组，返回仍回到原页面；重复启动不重复打开。
- 主界面的原位语音气泡仍走 `AssistantVoiceController` 的 start/stop/cancel，不经过以下票据协议；两条路径只共用 `ConfiguredAssistantSpeech` 的路由判断。

## 结构

```text
主界面：AssistantPage / 输入气泡
        │  start / stop / cancel
        AssistantVoiceController → ConfiguredAssistantSpeech
                                     ├─ 录音转写服务（用户配置的 OpenAI 兼容接口）
                                     └─ LocalSpeechBackend（Android）
                                            ├─ SpeechModelStore：检查已有模型（不会自动下载）
                                            └─ SherpaSpeechEngine：常驻 worker isolate
                                                   └─ sherpa_onnx OfflineRecognizer（SenseVoice）

悬浮入口：AssistantOverlayVoiceActivity（原生面板：权限、计时、采集、状态与动作）
        │  beginVoice / voice / cancelVoice（mission_book/assistant_workspace）
        AssistantWorkspaceBridge → AssistantVoiceChannel → ConfiguredAssistantSpeech（同上）
```

- `AssistantSpeech` 仍只暴露 start/stop/cancel；`WarmUpSpeech` 只加载已有模型，使用转写服务时不预热本地模型。
- 未下载时点语音先提示设置入口，不占麦克风。已有模型时录音与模型加载并行，停止后等待识别结果。
- 设置页的独立下载操作才会联网；离开下载区域会取消进行中的下载。临时文件不参与识别，失败不会被当作安装成功。网络不可达时提供重试，不隐式更换第三方镜像。
- FFI 对象（`OfflineRecognizer`、`OfflineStream`）只存在于 worker isolate；主 isolate 只传模型路径、`Float32List` 和文字，避免主线程 decode 造成界面冻结。
- `SpeechModelStore` 用条件导入隔离 `dart:io`，Web 使用 stub，不把平台代码带进浏览器构建。

## 失败与恢复

| 场景 | 行为 |
| --- | --- |
| 麦克风未授权 | 可见错误，建议检查系统权限或改用文字 |
| 录音过短 / 空音频 | 明确提示“录音太短”或 `emptyAudio`，不提交空文字 |
| 模型未下载（`offlineModelMissing`） | 不启动麦克风；悬浮面板显示契约文案并提供「打开语音设置」 |
| 模型摘要校验失败（`offlineModelInvalid`） | 提示重新下载，不进入录音 |
| 模型加载失败（`offlineModelInitFailed`） | 提示重试或改用文字，可打开语音设置；不缓存成永久成功 |
| 远程未配置 / 配置无效 | `remoteConfigMissing`/`remoteConfigInvalid`，提供「打开语音设置」；不静默切回离线 |
| 模型下载失败/取消 | 清理临时文件，允许用户重新下载；不影响文字和任务功能 |
| 识别超时 | `transcribeTimeout`，提示重试或改用文字；不把超时当成功 |
| 悬浮转写失败 | 显示契约给的 `message`；`cancelled` 静默关闭；其它提供重试/重录/使用文字 |
| 票据失效 / 草稿切换 | `ticketInvalid`/`draftChanged`，清理票据，不写入其它草稿 |
| 取消/返回/切换会话 | generation 隔离迟到文字，录音资源释放；`cancelVoice` 幂等 |
| 应用退到后台 | 悬浮面板结束本轮票据（沿用原生命周期保护） |
