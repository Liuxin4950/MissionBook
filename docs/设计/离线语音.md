# 离线语音识别（SenseVoice）

本轮把助手语音从“系统识别服务/系统弹窗”改为 App 内录音 + 端侧 SenseVoice，不再依赖手机厂商的识别 UI、默认服务或转写 API Key。

## 结论与边界

- 识别引擎：`sherpa-onnx` 与 Android 原生包统一为 1.13.8，模型 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`（int8，约 230 MB）。旧文档的 1.12.21 已更正。
- App 内录音：`record` 采集 16kHz、单声道、PCM16，最长 30 秒；停止后转换浮点采样交给 worker。
- 模型部署：不随 APK 打包。在助手设置内主动下载到私有目录，显示进度，可取消和重试；流式写 `.part`，长度和 SHA-256 均通过后才改名。固定下载来源和版本见[模型说明](../../assets/models/sensevoice/README.md)。旧版私有目录模型首次完整校验后复用。
- 当前平台：Android 可用。Windows 端 `sherpa_onnx` 的 Windows 预编译包与自带 ONNX Runtime 版本不匹配（DLL 请求 API 28，运行时仅 1.17.1），本轮不启用本地引擎；Windows 和浏览器仍可使用已有的录音转写服务，或文字输入。
- 语音结果只填回输入框，不自动发送；取消、超时、模型缺失都走真实错误提示，不伪造成功。

## 结构

```text
AssistantPage / 输入气泡
        │  start / stop / cancel
AssistantVoiceController
        │  AssistantSpeech
ConfiguredAssistantSpeech
   ├─ 录音转写服务（用户配置的 OpenAI 兼容接口）
   └─ LocalSpeechBackend（Android）
          ├─ SpeechModelStore：检查已有模型（不会自动下载）
          └─ SherpaSpeechEngine：常驻 worker isolate
                 └─ sherpa_onnx OfflineRecognizer（SenseVoice）
```

- `AssistantSpeech` 仍只暴露 start/stop/cancel；`WarmUpSpeech` 只加载已有模型。使用转写服务时不预热本地模型。
- 未下载时点语音先提示设置入口，不占麦克风。已有模型时录音与模型加载并行，停止后等待识别结果。
- 设置页的独立下载操作才会联网；离开下载区域会取消进行中的下载。临时文件不参与识别，失败不会被当作安装成功。网络不可达时提供重试，不隐式更换第三方镜像。
- FFI 对象（`OfflineRecognizer`、`OfflineStream`）只存在于 worker isolate；主 isolate 只传模型路径、`Float32List` 和文字，避免主线程 decode 造成界面冻结。
- `SpeechModelStore` 用条件导入隔离 `dart:io`，Web 使用 stub，不把平台代码带进浏览器构建。

## 参考项目

- [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 官方 Flutter 示例 `non_streaming_vad_asr`：SenseVoice 配置、`OfflineRecognizer` 调用顺序、模型从 assets 复制到应用目录。
- [fantasyao/shengwuji](https://github.com/fantasyao/shengwuji)（声物记，Apache-2.0）：常驻识别 worker isolate、FFI 对象不跨 isolate、模型随包部署与首次复制、录音 PCM 转浮点。本实现按其结构改写，未复制其业务代码。
- 模型许可：上游 SenseVoiceSmall 模型卡标记 `model-license`；旧文档将权重写成 Apache-2.0 不准确，已改为引用上游模型许可。来源、许可与摘要见 [模型说明](../../assets/models/sensevoice/README.md)。

## 失败与恢复

| 场景 | 行为 |
| --- | --- |
| 麦克风未授权 | 可见错误，建议检查系统权限或改用文字 |
| 录音过短 | 明确提示“录音太短”，不提交空文字 |
| 模型未下载 | 不启动麦克风，提示助手设置的可选下载入口 |
| 模型下载失败/取消 | 清理临时文件，允许用户重新下载；不影响文字和任务功能 |
| 模型校验/加载失败 | 明确报错；不把失败缓存成永久成功 |
| 识别超时 | 提示重试或改用文字；不把超时当成功 |
| 取消/返回/切换会话 | generation 隔离迟到文字，录音资源释放 |
| 应用退到后台 | 语音取消（沿用原生命周期保护） |
