# 悬浮语音通道契约（本轮冻结）

> 2026-11-23 · **实施契约**。配套[Android 悬浮助手与离线语音统一实施计划](Android悬浮助手与离线语音统一实施计划.md)「建议桥接协议」。A（原生悬浮）、B（Dart 语音后端）、C（原生录音界面）同时按本文件实现；改方法名、payload、错误码或状态映射，先改本文件并通知另一方与集成者（D）。

## 1. 通道与方法

- 通道：现有 `mission_book/assistant_workspace`（`AssistantWorkspaceHost` / `AssistantWorkspaceBridge.channel`）。原生 `AssistantWorkspaceHost.call` 会自动附加 `generation`，Dart 收到后先比对工作区代次，不一致一律拒绝。
- 方法：`beginVoice`、`voice`、`cancelVoice`。三个方法都由 Dart `AssistantWorkspaceBridge` 处理；Kotlin 只做调用与展示，不判断模型目录、不读安全存储、不持有转写 Key。
- 录音采集、权限、计时、PCM 长度上限（16 kHz 单声道 PCM16、≤30 秒 ≈ 960000 字节）仍由原生 `AssistantOverlayVoiceActivity` 负责；识别后端选择只归 Dart `ConfiguredAssistantSpeech`。

### 1.1 `beginVoice`

- 入参：`{"ticket": String, "generation": int}`（`ticket` 由 Kotlin 用 `UUID` 生成并传入 Activity）。
- Dart 行为：准备当前外部助手草稿（`assistant.prepareExternalEntry()`），读取已保存语音设置，预检并**准备**所选后端，把 `{ticket, draftKey, mode, generation, routeSnapshot}` 固定在本轮票据里。
  - 离线（`useTranscription=false`）：只校验并 `prepare` 已安装 SenseVoice；不申请麦克风、不下载、不访问网络。模型缺失/校验失败/worker 初始化失败返回明确错误。
  - 远程（`useTranscription=true`）：只校验已保存 endpoint/model 与独立凭据（`MISSIONBOOK_TRANSCRIPTION_API_KEY`），不上传音频、不返回凭据。
  - 并发：已有票据未终结时返回 `busy`，不取消/覆盖 `AssistantVoiceController` 正在使用的录音会话。
- 返回（成功）：

```text
{ "ready": true, "mode": "offline"|"remote", "draftKey": String,
  "label": "离线语音"|"录音转写服务" }
```

- 返回（失败，不抛异常，便于原生直接展示）：

```text
{ "ready": false, "mode": "offline"|"remote", "errorCode": …, "message": "中文可展示原因" }
```

错误码与文案（`message` 由 Dart 给，原生直接显示，不自行拼接）：

| errorCode | 场景 | message 示例 |
| --- | --- | --- |
| `offlineModelMissing` | 未安装 SenseVoice | `离线语音模型未安装，请先在语音设置中下载` |
| `offlineModelInvalid` | 摘要校验失败 | `离线语音模型已损坏，请重新下载` |
| `offlineModelInitFailed` | worker 准备失败 | `离线语音模型未能加载，请重试或改用文字` |
| `remoteConfigMissing` | 未配置 endpoint/凭据 | `录音转写服务未配置，请先完成语音设置` |
| `remoteConfigInvalid` | endpoint 非法 | `录音转写服务配置无效，请检查语音设置` |
| `workspaceUnavailable` | 工作区未就绪/会话已切换 | `助手正在准备，请稍后重试` |
| `busy` | 已有票据在准备/录音/转写 | `语音正在使用中，请稍后重试` |

- 新票据开始时，旧票据（若已终结）必须已释放；`beginVoice` 成功后原生才请求麦克风权限/启动 `AudioRecord`。`ready=false` 时原生绝不申请录音权限。

### 1.2 `voice`

- 入参：`{"ticket": String, "pcm": Uint8List, "generation": int}`。
- Dart 行为：校验 ticket 仍在、工作区代次未变、绑定草稿仍是可写目标；调用 `ConfiguredAssistantSpeech.transcribePcm`（沿用本轮固定的后端，不重新读设置切换模式）；成功只把文字追加到绑定草稿（保留原草稿，换行拼接），**不自动发送、不切换会话**。失败与取消都清理票据；迟到结果丢弃。
- 返回（成功）：`{"accepted": true, "draftKey": String}`。
- 返回（失败）：`{"accepted": false, "errorCode": …, "message": "中文可展示原因"}`，错误码：`ticketInvalid`、`draftChanged`、`workspaceUnavailable`、`emptyAudio`、`offlineModelInitFailed`、`remoteRequestFailed`、`remoteAuthFailed`、`transcribeTimeout`、`noSpeech`、`cancelled`、`failed`。
- 兼容：不再接受旧的 `{"key": …}` 写法；桌面 Windows 悬浮仍走 `voiceStart`/`voiceFinish`，不受影响。

### 1.3 `cancelVoice`

- 入参：`{"ticket": String, "generation": int}`。
- Dart 行为：使票据失效，取消可取消的录音/网络资源；幂等（票据不存在也返回成功）。
- 返回：`null`。

### 1.4 终结路径

- Activity 关闭/`onDestroy`/`onPause` 未完成、权限拒绝、预检失败、超时、工作区 `detach`/重建、新一轮接管，都调用 `cancelVoice` 或让 ticket 自然失效。
- 重复 `voice` 提交只允许一次产生文本：第二次必须返回 `ticketInvalid`。重复 `cancelVoice` 幂等。
- 成功文本回填后，Activity 以 `ticket + draftKey` 调用 `AssistantOverlayService.voiceDone(ticket, draftKey)`；服务校验草稿仍是当前会话后打开该草稿的对话输入区。若原草稿已失效，保留明确错误，不写入其它草稿。

## 2. 状态与原生 UI 映射（C 使用）

| Dart 返回 | 原生界面 |
| --- | --- |
| `ready=true, mode=offline` | 进入录音准备完成，显示「离线语音」；申请麦克风后录音 |
| `ready=true, mode=remote` | 先显示「录音将发送到你的转写服务」一次性说明，再请求麦克风 |
| `ready=false` | 显示 `message`，提供「使用文字」；`offline*`/`remote*` 错误额外提供「打开语音设置」 |
| `voice` 成功 | 关闭面板，通知服务回到原草稿输入区，不自动发送 |
| `voice` 失败 | 显示 `message`；`cancelled` 静默关闭；其它提供重试/重录/使用文字 |

## 4. 导航交接（D 使用）

- 原生「打开语音设置」→ 启动 `MainActivity`，携带一次性路由 `EXTRA_ASSISTANT_ROUTE = "voiceSettings"`；`MainActivity` 通过现有 `assistantIntent`/通道把 `{"route": "voiceSettings"}` 交给 Flutter，`AppShell` 消费后打开现有助手设置 → 语音输入页，返回后回到悬浮语音入口。不得只启动主界面。
- 该路由是一次性消费：热恢复、重复启动不重复打开；消费失败保留原页面并提示。
