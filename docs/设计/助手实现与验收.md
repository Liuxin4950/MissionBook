## 离线语音与可选模型（2026-10-29，0.2.10）

助手语音采用 App 内录音 + 端侧 SenseVoice（`sherpa-onnx`），不再调用系统识别服务或系统弹窗。模型约 230 MB，不随 APK 打包；在“助手设置 → 语音输入”按需下载，带进度、取消、失败重试、长度与 SHA-256 校验。打开助手和录音预热不自动联网；未下载时先提示，不启动麦克风。旧版已部署的完整模型可复用。识别在常驻 worker isolate 中执行，最长录音 30 秒，只填回输入框，不自动发送。Android 启用；Windows/浏览器可用录音转写服务或文字。详细结构、参考项目、失败路径和验证边界见[离线语音](离线语音.md)。

- 权限：默认每次工具操作确认；宽松只读自动、所有写入确认；完整自动执行现有工具。默认档的读取也有真实允许/取消回调，取消不查询。旧开关按旧行为迁移，权限仍由宿主判断；未增加批量或直接数据库写入能力。
- 附件：真实 Web/Android/Windows 文件选择，图片限 PNG/JPEG/WebP/GIF，每张 4 MiB；UTF-8 文本限 256 KiB，支持 TXT/Markdown/CSV/JSON 等。每条最多 4 个、合计 8 MiB、文本正文合计 32000 字符；预览、移除、返回保留草稿、发送和会话恢复接通。PDF/Word 尚不解析，明确提示先转换。已发内容进入会话日志及原有数据库备份；未发草稿只在当前进程内保留。
- 语音：移除 Android 非默认识别器强制选择，Web 显式中文；初始化错误也显示，权限/网络/麦克风/语言服务错误保留类别。浏览器不支持可靠本地模式时明确拒绝。新增录音转写配置：独立地址、模型、Key，50 秒单声道 PCM 转 WAV，停止后通过兼容接口转写为可编辑文字；取消中断请求并隔离迟到结果，音频不进会话/备份。聊天 Key 不自动分享给语音服务。没有内置或自建的免费识别服务器，使用此路径需用户配置可达服务；浏览器服务还需允许 CORS。

## 当前结构

```mermaid
flowchart TD
    Page[已有任务、目标、节点工作区] --> Entry[已接通 AssistantLauncher 悬浮圆泡]
    Entry --> Speech[系统识别或配置的录音转写]
    Speech --> Bubble[已接通原位转写与操作气泡]
    Entry --> Chat[已接通二级聊天路由]
    Bubble -->|展开保留会话| Chat
    Chat --> Controller[常驻 AssistantController]
    Bubble --> Controller
    Controller --> Core[agent_core 模型、循环、压缩与原文日志]
    Core --> Reads[有界只读投影与按需工具]
    Core --> Approval[工具授权与批准参数持久化]
    Approval --> Services[已有 MissionService / GoalService]
    Services --> Transactions[已有仓储事务、冲突检查与操作回执]
    Transactions --> Refresh[已有 changes 通知原页面重读]
    Core --> Sessions[Drift 会话日志与索引]
    Core -.后续功能仍须完成.-> Memory[任务总结与精简目标记忆]
```

页面只交付对象身份，不抓取整个屏幕或自动读取未保存草稿。文字页面用 Navigator 的二级路由覆盖原工作区，不调用主导航切换或清除 DetailPaneController。语音与文字读取同一个会话和提案。会话绑定稳定对象编号，切页面不能改变待确认提案的对象。
