## 2. 分层与生命周期

```text
悬浮 UI ─┐
聊天 UI ─┴→ 同一 App 工作区 → 正常会话 → 同一 Agent → 业务服务/事务 → 实际回执
Android 应用使用信号 [+ 用户授权的取样] → 监督判断 → 提醒气泡 / 普通会话历史
```

- **运行归属。** Android 用进程持有的一个可重新附接的主 FlutterEngine；前台和已启用的悬浮/监督按需持有它。工作区装配、桥接 ready 不能依赖 `AppShell` 的 Widget 已绘制。复用 App 的数据库、任务、记录、目标、设置和控制器；只移动需要共享的装配和关闭职责。不要启动第二套助手运行时或改造既有计划任务短时引擎。
- **契约。** Kotlin 管窗口、权限、事件、录音设备和投影；Dart 应用层管判断、会话、用户授权和命令；数据层管持久化。桥接命令校验工作区代次及请求身份；草稿、提案和回复另外校验目标 ID 或修订。窗口只展示有界快照，不获取凭据或提交权限。基座不识别 Android、任务阶段或监督策略。
- **资源关闭。** Activity 分离后若有已授权客户端，不取消它的对话；不用时收回引擎和桥接。区分后台、划掉主任务、进程回收、强停与重启；系统已终止就显示真实状态，不缓存投影授权票据，不静默重开视觉。恢复备份前冻结入口、递增工作区代次、停投影/录音、取消监督、等待业务事务和会话关闭；新工作区 ready 后才收新请求，监督须重新启用，旧授权和迟到事件不能跨工作区。
- **路由。** 截图、转写、发送、显示回复和确认不启动 `MainActivity`。只在用户主动选择打开会话、查看日程、回到任务或打开记录草稿时，以稳定 ID 交给现有导航；等冷/热启动路由就绪再消费一次。失效对象可解释，不回落到旧设置页。独立系统授权窗不等同于主界面跳转。

## 3. 监督权限与判断

默认关闭。是否显示悬浮球、是否启用观察、是否允许数据外发、普通工具权限分别判断。设置用图标、分段控件、模型名称和真实状态，不增加频率和阈值输入。

| 有效状态 | 能做什么 |
| --- | --- |
| 关闭 / 用户暂停 | 停止读取、取样和新模型调用，取消旧工作并释放主动投影。手动截图仍可单独授权；如本次截图正复用被撤的投影，则取消这一张，保留之前的草稿。稍后/本次不提醒只抑制提醒。 |
| 仅使用情况且系统权限可用 | 读取可信前台 App、估计连续时长和有限近期变化，可本地提醒。只有单独同意后才把最小概况发给明确的文字模型；绝不主动取图或发图。 |
| 允许画面且所有条件可用 | 使用情况继续作为基础；显式选择识图模型和接收服务，系统授权的整屏投影有效时按需取帧。无需逐张询问；不把单应用投影或未知授权范围当成整屏许可。 |
| 权限不足 / 画面或模型不可用 | 显示待授权、画面不可用或仅使用情况；仍有使用权限时可降级，否则不判断。不能悄悄换视觉模型或冒充已经看见。 |

1. **事实来源。** Android `UsageStatsManager.queryEvents` 做有界增量读取，合并同 App 活动切换。切换、锁屏、事件缺失、系统窗和时钟回拨后重新判断连续性。分屏、画中画等不能可靠辨别时表示未知，不累加成确定事实。只留有界最近概况，不做全量历史、通知内容或控件树采集。日程使用现有业务时钟、纯读快照和排期/计时规则，覆盖跨日及 EXTEND；计划上课不等于已经上课。
2. **提醒策略。** 授权时跨 App 持续感知，课表只提供何时值得开口的依据。以已有任务窗口/观察事件去重和限制打断；证据不足就询问或不提醒。只有使用情况时只陈述 App、时间及计划，不认定正在刷视频。默认等待、稍后和重复抑制走内部规则和测试；不做实时逐帧模型调用。
3. **单次判断。** 有值得核实的候选时，按许可送一次有界文字概况，模型只能输出「不提醒 / 提醒 / 请求看一帧」。也可由本地规则筛出需要看图的候选，但没有画面授权不得取样。有授权时每候选最多一帧，不带聊天、长期记忆或工具，单路在途；无图、超时、模型不可用或异常结果回到保守的使用情况判断。工具执行与监督模型分开。
4. **发送防线。** 授权绑定实际服务地址、服务身份和模型 ID；改地址、删/换模型、暂停、权限撤销、投影停止和工作区变化使授权或当前请求代次失效。取样前、取样后、交给传输层前复核授权、前台信号和代次。检测到切换即丢帧并取消晚到结果；使用事件不是画面来源的原子证明，已经发给接收方的请求也不能撤回。画面不可信、受保护或不可用时不发；不承诺识别所有敏感页面。授权保存在本机，排除应用导出和系统自动备份。原始信号/画面不进入日志、聊天附件、材料、长期记忆或备份。
5. **提醒与回应。** 助手提醒按一次性身份保存为普通会话的助手消息，不伪造用户输入。已有草稿、录音、生成或提案时只提示待查看，不抢焦点；点回复才打开提醒对应的会话。稍后和本次不再只作用于这次任务窗口或连续使用事件，不写任务。无悬浮权限时用已授权通知降级；两者都没有就留待 App 内回看，不伪造送达。

## 4. 悬浮交互与业务确认

- **一个投影拥有者。** 有可复用授权时，手动截取独占消费画面，暂停自动取样，复用同一投影；没有才由用户发起单次授权。单次完成/取消不能停止仍有效的持续投影。保留局部、全屏和长截图；采集帧去掉本应用操作控件。方向改变时废弃旧选区；需要时调整已建显示与 Surface，停止后申请新授权而非复用旧令牌。
- **一份草稿。** 发起截图时绑定草稿和一次性身份；完成交给原草稿并按顺序显示可预览/移除的缩略图。按 [AssistantAttachment](../../../lib/application/assistant/assistant_attachment.dart) 复用限额和模型能力，不为悬浮发明另一套。收起、切 App、取消截屏、预检失败保留草稿；未发草稿承诺同工作区进程内保留。是否已发送看日志；网络失败保留正常会话，不因未收到回调自动重发。交付或取消后清理原生文件，过期回收。
- **语音由用户触发。** 可见录音界面处理麦克风使用时权限，不打开主界面、不常驻监听。复用 [AssistantSpeech](../../../lib/application/assistant/assistant_speech.dart) 和[配置转写](../../../lib/data/assistant/configured_assistant_speech.dart)。若现有录音插件依赖主 Activity，给现有转写路径接一个用户可见的原生录音入口，不另配服务或调用未选择的供应商。完成可编辑回填，取消保留原草稿，拒绝权限可继续打字。
- **提案和回执同源。** 悬浮和主界面只显示同一轮的流式状态，不重复调用。问「有没有空」先核对明确的日期和起止，复用既有排期冲突规则检查该时间窗，不能从日程第一页没找到冲突就说有空。写提案按会话、调用号和当前版本确认，复用[安排卡](../../../lib/presentation/assistant/operations/assistant_schedule_card.dart)；权限为完全也不跳过。恢复未确认提案不自动写，结果未知先按回执核对。只有真实提交成功后才能显示「已加入」和对应对象。
- **相关 UI 放进旧页面。** 今天/周表的「现在/接下来」和回任务读取真实阶段，STOP 后仍需用户报告；不由使用情况推断完成。任务/节点上下文用已保存 ID 与有限步骤。手动截图显式「保存为记录」才打开原草稿表单，用户确认后经 `RecordService` / `MissionService` 正式保存；聊天发送和主动画面都不是材料。复盘读取实际报告和可用总结，提出后续任务、改期或再次尝试，不改历史。

## 5. 会话摘要持久化

- 延续默认关闭的「接续近期会话」和现有摘要模型。新会话首次实际发送时，选最近三个同范围的可用来源；只有提醒没有用户回应、运行中或结果未核实的会话不占名额。有界找候选，不扫描所有历史。收球、后台、静置不是结束；老会话续聊读原消息。
- `DriftSessionStore` 复用既有 `app_settings` 存放有界派生缓存，不改 schema。按来源会话 ID、实际日志修订、摘要模型身份与规则版本验证，不能只用毫秒更新时间。沿用有界输入、约 200 字和单项 8 秒；仅缺失或过期才重算，失败跳过，聊天继续。删除来源时清缓存；来源变更、接续关闭或相应遗忘后，发消息、继续和压缩前撤掉过期注入。
- 不传图片、附件正文、思考、工具回包、既有摘要或原始观察数据；只继承用户明确表达的事项和可区分的建议。缓存键空间从备份导出与恢复中过滤，恢复后的模型投影须重新验证来源；不能误删会话正文或其他设置。

## 7. 验收和停止条件

- **应用/数据检查。** 断言真正交给传输层的请求与实际事务次数：拒绝上传、切换/暂停时丢弃旧结果、范围与去重、摘要命中和失效、备份恢复、完全权限下悬浮依然确认、拒绝/重复操作、未知结果回执与跨日 STOP。原有任务事实闭环不变。
- **窗口和设备检查。** 连图、选区/长截图、中途取消、键盘与大字、语音权限/取消、边缘返回、旋转、窄屏/平板、后台重挂和只在显式操作时导航。以[产品三条流程](个人助手与任务联动.md#一次验收的三条流程)检查真机，另外实测系统停止投影、受保护画面、模型切换和进程重启。模型测试只用已配置服务与可公开画面；记请求数量和真实上下文，不以本机断言估算节省。
- **工程交付。** 格式化改动处、Flutter analyze、受影响应用/数据/界面测试、Kotlin 编译；触及基座时增跑基座测试。同步[现行架构入口](../../架构/README.md)及[教学变更](../../教学/变更记录.md)，记录保留与替代内容；规划阶段不改源码、不构建、不调用模型。
- **须先修再扩。** 一旦发现第二工作区、错误会话归属、未授权发图、确认绕过、任务阶段错误或不能可靠停止采集，停在该包解决。不得靠新表、平行业务状态、模拟数据、吞错或跳主界面作为临时实现。App 白名单/例外配置、设备使用报表、操控其他 App、独立 Plan 和云同步不纳入。

### 平台依据

- [Android MediaProjection](https://developer.android.com/media/grow/media-projection)：授权会话、显示调整、系统停止与资源清理。
- [UsageStatsManager](https://developer.android.com/reference/android/app/usage/UsageStatsManager)和[应用使用事件](https://developer.android.com/reference/android/app/usage/UsageEvents.Event)：使用权限、可获取区间和 Activity 信号。
- [后台启动前台服务约束](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)与[窗口画面保护](https://developer.android.com/security/fraud-prevention/activities)：检查录音和受保护画面边界，目标设备行为仍需实测。
