# 桌面小组件外观契约 v2（本轮冻结）

> 2026-11-23 · **实施契约**。配套[桌面小组件与平板工作区改版计划](桌面小组件与平板工作区改版计划.md)第 4 节。W1（原生）与 W2（Flutter 编辑器）必须按本文件同时实现；任一方要改字段、方法名或枚举值，先改本文件并通知另一方与集成者。字段名、枚举字符串、范围、默认值以本文件为准。

## 1. 外观结构（v2）

一份设备级外观同时作用于这台设备上的所有小、中、大组件。原生是默认值、取值域、持久化和最终回执的权威；Dart 同结构用于编辑草稿与预览。

| 键 | 类型 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `version` | int | `2` | `2` | 结构版本；缺失或非 2 视为无效，不静默覆盖 |
| `style` | string | `paper` / `index` / `minimal` | `paper` | 纸页清单 / 索引卡 / 极简 |
| `theme` | string | `system` / `light` / `dark` | `system` | 不跟随宿主动态取色 |
| `headerSp` | int | 11–17 | `12` | 卡片标题 |
| `taskSp` | int | 11–20 | `12` | 任务名（含小号，取代 18sp） |
| `metaSp` | int | 10–16 | `11` | 日期、时间、状态、更多 |
| `horizontalPaddingDp` | int | 8–16 | `10` | 外侧左右 |
| `verticalPaddingDp` | int | 4–12 | `6` | 外侧上下 |
| `rowPaddingDp` | int | 3–9 | `4` | 行内上下 |
| `rowGapDp` | int | 0–8 | `4` | 行间隔 |
| `radiusDp` | int | `8` / `12` / `16` | `16` | 外框圆角；行角按样式固定 |
| `showDetails` | bool | — | `true` | 关闭时只显示任务名，保留 `timeMode`/`showStatus` 选值 |
| `timeMode` | string | `none` / `start` / `range` | `range` | `range` 在放不下时才降级为开始时间，不改保存值 |
| `showStatus` | bool | — | `true` | 阶段文字 |
| `showDate` | bool | — | `true` | 题头日期 |
| `showMore` | bool | — | `true` | 尾部「另有 N 项」，只隐藏计数，不隐藏打开入口 |
| `rowLimit` | int | 1–5 | `5` | 中/大显示上限，实际取 `rowLimit、容量、快照条数` 最小值 |

- 小号始终最多一项（由规划器裁到 `n≤1`），与 `rowLimit` 无关；`rowLimit` 仍保存用户选值。
- 非法写入一律拒绝：未知枚举、非整数、越界、`version≠2`、`version` 缺失、缺失键按默认补齐后仍非法时整体拒绝（`PlatformException(code: "invalidAppearance")`，中文 `message`）。Dart 侧在提交前用同一取值域校验，服务端拒绝时保留草稿并显示 `message`。
- 迁移：v2 文件不存在时读旧 `SharedPreferences("today_widget_appearance")` 的 `theme`/`textSize`。旧 `theme` 原样保留；旧 `standard` 映射默认（12/12/11），旧 `large` 映射 `headerSp=15, taskSp=15, metaSp=13`。迁移结果立即写成 v2，旧键保留但不再作为来源。
- 存储：`AtomicFile(noBackupFilesDir/today-widget-appearance-v2.json)`，UTF-8 JSON。文件存在但缺少 `version`、损坏或不可解析时使用默认值、标记 `recovered=true` 并重写一份合法文件；不覆盖无法识别的高版本（`version>2` 时只读默认、不写）。
- 旧版本不得读取 v2 之外的键判定外观；Dart 不直接读原生文件。

## 2. 通道 `mission_book/today_widget`

现有通道不变，外观方法为下列四个（`getAppearance`/`setAppearance` 兼容保留同名）；`beginSnapshot`/`publish` 等快照方法按 2.5 原样保留。

### 2.1 `getAppearance`

- 入参：无。
- 返回 `Map<String, Object?>`：

```text
{
  "version": 2,
  "appearance": { …第 1 节全部键，已归一化… },
  "defaults":   { …第 1 节全部键的默认值… },
  "recovered":  bool,          // 存储损坏或迁移失败时为 true
  "source":     "v2" | "migrated" | "defaults"
}
```

- 读不到原生偏好（通道异常）由 Dart 抛错并显示重试；`source=defaults` 与读取失败不是一回事。

### 2.2 `setAppearance`

- 入参：`{"appearance": { …第 1 节全部键… }}`。
- 行为：校验 → 原子保存 → 以同一份快照重绘既有实例 → 返回回执。保存与重绘是两个结果，保存成功不能因重绘失败报失败。
- 返回：

```text
{
  "appearance": { …保存后的归一化外观… },
  "widgets": "noInstances" | "requested" | "partialFailure" | "failed"
}
```

- `requested` 只表示 `updateAppWidget` 已交给系统，不代表 Launcher 已绘制。`partialFailure`/`failed` 时编辑器显示「已保存，桌面暂未更新」并提供 `redrawWidgets`，不回到旧值。

### 2.3 `redrawWidgets`

- 入参：无。只用已保存外观与已缓存快照重绘，不查 SQLite、不读任务库。返回 `{"widgets": 同 2.2 枚举}`。

### 2.4 `previewAppearance`

- 入参：`{"appearance": { …草稿… }, "sizeClass": "small"|"medium"|"large", "theme": "system"|"light"|"dark"}`。`theme` 是预览开关的临时覆盖，不回写偏好；`sizeClass` 只影响预览。
- 行为：纯计算。不写偏好、不查 SQLite、不更新 Launcher。用与桌面同一份规划器（`TodayWidgetLayoutPlanner`）和同一份示例快照。
- 返回：

```text
{
  "version": 2,
  "sizeClass": "small"|"medium"|"large",
  "sizeSource": "widget" | "reference",
  "widthDp": int, "heightDp": int,
  "theme": "light"|"dark",             // 已解析的预览主题（system 按系统）
  "style": "paper"|"index"|"minimal",
  "colors": {
    "surface": ARGB int, "content": ARGB int, "rowSurface": ARGB int,
    "spine": ARGB int, "primaryText": ARGB int, "secondaryText": ARGB int,
    "accent": ARGB int, "warn": ARGB int, "hairline": ARGB int
  },
  "metrics": {
    "horizontalPadding": int, "verticalPadding": int, "rowPadding": int,
    "rowGap": int, "radius": int, "headerSp": int, "taskSp": int, "metaSp": int,
    "headerHeight": int, "footerHeight": int, "rowHeight": int
  },
  "header": { "visible": bool, "left": String, "right": String, "count": String? },
  "rows": [ {
      "time": String?, "title": String, "status": String?,
      "showTime": bool, "showStatus": bool, "titleMaxLines": int,
      "progress": String?                     // 计划进度文案，仅当前时段行
  } ],
  "footer": { "visible": bool, "kind": "more"|"headerCount"|"none", "text": String? },
  "empty": "none" | "waiting" | "empty",
  "overflow": "none" | "tight" | "headerOnly",
  "rowLayout": "wide" | "stacked",
  "spineVisible": bool,
  "dividerVisible": bool,
  "sample": true
}
```

- `widthDp`/`heightDp`：该尺寸类别下已有实例的真实有效尺寸（`sizeSource="widget"`），没有实例时用参考尺寸 `109×109` / `220×109` / `220×220`（`sizeSource="reference"`）。
- 示例快照固定 6 条，明确是示例：第 1 条当前时段（`进行中` + 计划进度文案）、第 2–5 条待开始、第 6 条自选时间。日期用真实今天（上海）。`sample` 恒为 `true`，Flutter 必须显示「示例数据」与尺寸来源。
- `rows` 只含规划器判定可见的行；`titleMaxLines` 为 1 或 2。`rowLayout` 是规划器最终选定的行版式（`wide` 三槽 / `stacked` 上下），`spineVisible` 与 `dividerVisible` 由样式决定（`index` 有书脊，`paper`/`minimal` 无行底；`paper` 有分隔线、`minimal` 也有分隔线、`index` 行间用间隔不用分隔线）。Flutter 预览必须直接使用这三个字段，不自行推断。`headerOnly` 表示空间不足时退化为题头入口（`rows` 为空），`waiting`/`empty` 空态与「空间不够」不是一回事。
- 颜色按草案 `theme` 解析（`system` 由原生读系统夜间模式），Flutter 不自己推导颜色。

### 2.5 外观方法与既有职责的边界

- `pendingWidgetOpen`/`consumeWidgetOpen`、快照发布、深链与日期轮换**不改**。
- 外观相关调用不触发任务查询、写入或重查；原生不按墙钟重算执行阶段。

## 3. 视觉令牌（原生与 Flutter 对照）

| 角色 | 原生常量（`TodayWidgetAppearance`/`colors.xml`） | Flutter |
| --- | --- | --- |
| 明亮外底 | `#F7F8F5` | `AppColors.background` |
| 明亮正文面 | `#FFFFFF` | `AppColors.card` |
| 明亮浅绿 | `#EEF2EC` | `AppColors.primarySoft` |
| 森林绿 | `#244D3D` | `AppColors.primary` |
| 主文字 / 次文字 | `#282E2A` / `#626A64` | `AppColors.textPrimary` / `textSecondary` |
| 细线 | `#E0E5DD` | `AppColors.hairline` |
| 深色外底 | `#1B251F` | 仅组件 |
| 深色正文面 | `#202C24` | 仅组件 |
| 深色强调面 | `#26382E` | 仅组件 |
| 深色主/次文字 | `#EEF2EC` / `#B8C9BE` | 仅组件 |
| 深色品牌绿 | `#A7C9B3` | 仅组件 |
| 深色待确认 | `#E7C48B` | 仅组件 |

- 样式差异：`paper` 行用轻分隔、无行底；`index` 行用 `rowSurface` 浅色条 + 左侧 `spine` 3dp 细脊，行角 `8dp`；`minimal` 无行底无色条，只有文字与分隔。
- 行触控：原生桌面内紧凑行目标 `32dp`，可用高度足够时补到 `48dp`（仅在不减少行数、不隐藏尾部时）；整行可点，点击打开对应任务详情。

## 4. 验收锚点（自动化）

- 原生纯规划器测试：`n=0/1/2/5/6`、容量不足、`rowLimit` 夹取、`showDetails=false`、`timeMode=none`、自选时间、大字与非线性字体缩放、`220dp` 三槽与上下布局切换。
- 迁移测试：v1 `standard`/`large`、损坏文件、未知高版本、无效枚举拒绝。
- Dart 测试：模型往返、越界拒绝、保存回执四态、预览回执解析、非 Android 不显示入口。
- 不把 `updateAppWidget` 请求成功当作桌面已绘制。
