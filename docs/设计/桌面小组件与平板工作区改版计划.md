## 1. 目标与边界

- Android 桌面小组件默认换成 MissionBook 的暖白与森林绿，标准字号收紧，行高由内容决定。用户在「我的 → 设置 → 界面 → 桌面小组件」直接调整外观、字号、间距和详细信息；已有组件不用删除重加。
- 平板的「橱窗门」是工作区与书祺之间贯穿上下、整高可拖的分隔结构，不是居中的六点按钮。侧栏文字与图标居中，AI 发送按钮减小可见面积，今天页计划日程按自身栏宽排版。
- 设计决定：小组件配置先全局应用于**这台设备上的所有小、中、大组件**，按每个组件的真实尺寸适配；不做逐实例配置、主题下载、任意透明背景或新后台服务。应用本体仍是现行浅色主题，桌面组件可独立跟随系统或选浅/深。
- 不更改任务数据表、任务阶段、调度、提醒、助手发送权限、会话存储及普通详情导航。不上线 iOS/Windows/Web 桌面组件；应用侧导航、日程和聊天布局需保留其他已支持平台的行为。

## 4. Android 桌面小组件

### 4.1 设置与可调规格

在现有「界面」分区的「桌面小组件」行**原位展开**编辑器，不新增必经路由，不把高级设置再拆进子页。预览用「小 / 中 / 大」分段，显示明确标注的示例数据；切换尺寸仅改变预览，不改偏好。在实际可用宽度 ≥ `800dp` 且两列能容纳放大后的控件时，左预览右设置，其他情况依次纵排。数值项提供带单位的 Slider 与 `− / +`，可精确逐级调；日期、详情等用开关，选样有可见选中和读屏状态。表单与预览均可随页面滚动。正常路径从其他顶层开始：切「我的」1 次、进入「设置」1 次、展开和保存都原位；必要返回计作第 3 次。

| 配置 | 可选值与默认值 |
| --- | --- |
| 样式 `style` | **纸页清单（默认）**：开放任务行、细分隔，只有焦点行浅绿标记；**索引卡**：按内容收高的浅色任务条，左侧小书脊；**极简**：单底面，纯字和分隔，无行底色和色条。切样式不重置用户已调的数值或信息开关。 |
| 色彩 `theme` | 跟随系统（默认）/浅色/深色；不跟随宿主动态取色。 |
| 字号 | 卡片标题 `headerSp`：`11–17`，默认 `12sp`；任务名 `taskSp`：`11–20`，默认 `12sp`（包括小号，取代 18sp）；日期、时间、状态、更多 `metaSp`：`10–16`，默认 `11sp`。步长 `1sp`，不自适应缩小。 |
| 间距 | 外侧左右 `horizontalPaddingDp`：`8–16`，默认 `10dp`；外侧上下 `verticalPaddingDp`：`4–12`，默认 `6dp`；行内上下 `rowPaddingDp`：`3–9`，默认 `4dp`；行间隔 `rowGapDp`：`0–8`，默认 `4dp`，步长均 `1dp`。调整间距会重算可见行数，不只改 CSS 式留白。 |
| 外形 `radiusDp` | 外框 `8 / 12 / 16dp`，默认 `16dp`；行角按样式固定（索引卡 `8dp`），浅/深不改变几何。Launcher 外层遮罩以系统为准。 |
| 详细 `showDetails` | 默认开；关闭时只展示任务名，不展示时间/阶段；同时保留这两个细项的选值，再开启时恢复。`timeMode` 为「不显示 / 开始时间 / 开始–结束」，默认「开始–结束」；`showStatus` 默认开。自选任务有时间位时显示「自选时间」而不填假时间。隐藏字段也不出现在相应任务的读屏摘要。 |
| 头尾和数量 | `showDate`、`showMore` 默认开；`rowLimit` 在 `1–5` 中选，默认 `5`，中/大实际显示取 `设置上限、实际容量、快照条数` 最小值。小号始终最多一项；有未显示任务时按总数计算 `另有 N 项`，不把上限当总数。关闭“更多”仅隐藏计数，标题/空态仍可打开今天。 |

编辑使用同一份 `已保存 / 草稿 / 保存中` 状态。默认预览中号；分组顺序为「预览 → 样式与颜色 → 字号 → 间距 → 显示内容 → 恢复默认 / 保存」。切到预览的浅、深示例可检查颜色，独立于真正的主题选择。滑动或切换仅刷新预览，**保存**才写一次；无改动时禁用保存，成功就地反馈，不强制退出；「恢复默认」只改草稿。收起编辑器或离开设置前对未保存修改走现有确认（侧栏换页使用详情离开守卫，顶栏与系统返回也走同一判断），保存中防重入；加载时不猜旧值，失败给重试；保存失败保留已输入的草稿。无组件也可保存作为将来默认值。Web、Windows 等不显示该项，不发 Android 通道调用。

### 4.2 布局、预览与回退

```text
小号 / 窄槽（示意）                 中大号 / 宽槽（示意）
┌ 今日             11/23 ┐         ┌ 今日任务                     11月23日 ┐
│ ▌品牌与营销管理实务    │         │ 08:00–09:40  ▌品牌与营销管理实务  进行中 │
│  08:00 · 进行中        │         │ 14:00–15:40   Python程序设计基础  待开始 │
│              另有 2 项 ›│         │                        另有 N 项 ›     │
└────────────────────────┘         └────────────────────────────────────────┘
```

- 小号沿用[现有焦点排序](<../../lib/data/notifications/today_widget_bridge.dart#L44-L69>)，任务名至多两行；中大号沿用原日程顺序，宽时用时间—任务—状态三槽，窄时标题一行、时间与阶段归入同一行辅助信息。`220dp` 是三槽候选宽度，不是保证：按缩放后的实际文字宽度先保任务名槽，再决定是否改为上下布局。题头 `24dp`、尾部 `20dp` 为测量下限，字体变大可增高。只在放不下时把「开始–结束」简化为开始时间，再不足时优先可见阶段（已关闭阶段时保留时间）；不改用户保存的选项。读屏保留快照中的完整任务名称和已开启的真实详情。自选与无结束遵循真实字段，不拼接空值。
- **先计算，再构建。** 原生纯布局规划器接受尺寸、格式化字符串、偏好、字体度量和系统缩放，返回版式、字段、行数和溢出位置。同一份计划供桌面与预览使用。容量从实际高宽扣外边距、按字体测出的头尾/行高、`32dp` 任务行触控下限、行间隔；逐个尝试 `n`，能显示最多行时优先。同一 `n` 可用时，优先用尾部 `另有 N 项`；尾部会挤掉一行、题头又装得下时改用头部 `+N`（装不下则不显示计数，不能盖住标题或日期），题头仍打开今天，读屏使用完整数量。只有不减少行数、也不用隐藏尾部时，才把行触控高补到 `48dp`，不继续随余量变高；内容超出则由内容决定。`wrap_content` 从上排，`n=0` 时只显示可点「查看今日任务」，不强塞行。
- 空快照与真实空日分开：无当日有效快照是「等待同步」，有快照且确实零项才是「今日暂无任务」，空间不够不是空日。过紧时先换紧凑版式；保持用户显式隐藏的字段不出现，保不住完整行就减行或回退到题头入口，不用更小字号硬塞。长中文/英文、跨日或无时间需要分别验证，排序与深链不变。
- **设置内实时预览**：Flutter 展示交互表单，使用 Android 同一布局规划器的只读预览回执（推荐在现有通道上加 `previewAppearance`，输入草稿与尺寸类别，返回已排版计划、颜色角色和示例条目）。三种参考尺寸 `109×109 / 220×109 / 220×220dp`；可选从现有组件中取同类的有效尺寸，尺寸来源标清；没有组件用参考值。采用合并刷新和 latest-wins，拖动不查询 SQLite、不写偏好、不更新 Launcher。Flutter 画同一计划，字体和 Launcher 裁边可能有微差，不称为系统桌面截图。选择器 `previewImage` 与原生默认新视觉一并更新；`previewLayout` 可在 API 31+ 提供默认静态示例，不要求 API 35 动态选择器和每位用户的设置实时同步。

### 4.3 原生实现契约与风险

1. **偏好单一来源。** 在[原生外观](<../../android/app/src/main/kotlin/chat/liuxin/mission_book/TodayWidgetAppearance.kt>)和[Dart 外观模型](<../../lib/data/settings/today_widget_appearance.dart>)建立 `version: 2` 的完整结构。Dart 解析返回值并提供编辑草稿；原生是默认值、取值域、持久化和最终回执的权威。写入拒绝未知枚举、非整数、越界、无效版本；存储损坏采用安全默认且可见恢复，未知新版本不静默覆盖。推荐复用 `AtomicFile` 模式，文件单独放 `noBackupFilesDir`，保证保存和已提交值切换同一边界。旧 `SharedPreferences` 仅在 v2 不存在时读，保留浅/深/系统选项；旧「标准」映射新默认，「大字」映射 `15/15/13sp`。设备既有组件必须通过原 provider 原地升级；不做任务库迁移、不清空本地数据。若仍使用旧偏好作为迁移来源，核对并排除该设备外观的 Android 系统云备份/迁移条目；不修改 MissionBook 业务备份清单。
2. **保存与桌面更新是两件事。** `getAppearance` 返回归一化偏好与默认；`setAppearance` 验证后原子保存，回执同时携带保存后的偏好和 `无实例 / 已请求重绘 / 部分或全部请求失败`。已保存但重绘请求失败显示「已保存，桌面暂未更新」并提供只用缓存重绘的操作，不让编辑器回到旧值；真正未保存保留草稿，回执丢失先读回核对。`updateAppWidget` 返回只意味着请求已交给系统，不代表 Launcher 已绘制。每批使用同一份外观快照；把原生写入与刷新按序，防止样式更新前的旧重绘覆盖新外观，单个实例异常不影响其它实例。
3. **按原生能力适配。** 保留[三个 provider 及现有 resize](<../../android/app/src/main/kotlin/chat/liuxin/mission_book/TodayWidgetProvider.kt#L24-L55>)。API 31+ 读取 `OPTION_APPWIDGET_SIZES`，过滤非有限/非正尺寸，去重且限制 size-map 最多 16 个，超限时缩为保守有效尺寸，不把两轴最大值拼成当前尺寸。API 24–30 或 OEM 不报尺寸时用保守 `MIN_WIDTH/MIN_HEIGHT`、无效则以 provider 默认回退。使用 RemoteViews 支持的 TextView / ImageView / LinearLayout / FrameLayout；`setTextViewTextSize` 传 `SP`，测量用支持非线性字体缩放的 `TypedValue` 和实际字体度量，别直接 `sp × fontScale`；`setViewPadding` 接收 `px`，只在边界转换。API 31+ 的动态 margin/height/color 方法带版本门；旧版用布局资源、padding 和装饰留白实现相同可调功能，用实际圆角形状资源而非只改 outline。避免位图化整个组件或通过反射调不支持的方法。
4. **别让宿主留下旧视图。** 每次明确设可见性、颜色、文字、间距和点击绑定，包括显式深色切回系统、详情关开、两行改为一行；保留按组件实例/任务区分的 [PendingIntent](<../../android/app/src/main/kotlin/chat/liuxin/mission_book/TodayWidgetProvider.kt#L389-L399>)。浅深/系统字号变化需验证 Launcher 重应用；既有尺寸回调、回 App 时和下次原生更新重算作为安全兜底，不承诺所有 OEM 在 App 未运行时瞬时刷新，不为外观加轮询。
5. **任务路径不变。** [快照发布](<../../lib/data/notifications/today_widget_bridge.dart#L151-L158>)继续调用 `MissionService.findScheduledOn`；[生产仓储](<../../lib/data/repositories/mission_queries.dart#L564-L617>)从最新排期组装完整 `MissionDetail`，其[唯一派生](<../../lib/domain/entities/mission_detail.dart#L20-L41>)包含 STOP 之后的 `reportPending`。保留上海「今天/明天」、至多五条加焦点、既有前后台刷新与代次、AtomicFile 快照、移除组件的清理。外观保存/预览不触发重查或任务写入，Kotlin 不用墙钟重新推算执行阶段。没有确认就不显示成已完成。

## 5. 平板/宽屏：橱窗门、侧栏和聊天

### 5.1 贯穿上下的橱窗门

```text
┌────────┬────────────────────────┬──────┬────────────────────────┐
│ 导航栏 │ 今天 / 其他工作区      │  ║   │ 书祺顶栏               │
│        │ 页面滚动               │  ║   │ 对话独立滚动           │
│        │                        │  ║   │                        │
│        │ 当前任务栏             │  ║   │ 输入区                 │
└────────┴────────────────────────┴──────┴────────────────────────┘
                                  24dp 整高拖动区，不覆盖两边的控件
```

- 只在助手会话是**实际可见栈顶**、左右面板空间够时显示。按用户确认，并排时橱窗门**总占宽 `24dp`**，中间画宽 `8dp` 的浅绿门轨和 `1dp` 细边，悬停、聚焦、拖动时加强品牌色；不放六点块或大按钮。整条 `24dp` 槽都能水平起拖，不加两侧隐形扩区。从 App 内容安全区顶接到底，键盘出现时止于可用内容底部，不随两栏内容滚动。该宽度只用于全高分隔控件，不调小普通按钮的 `48dp` 触控标准；普通详情仍用 `16dp` 间距。
- 助手专用门槛按扣除导航与系统侧边后的正文宽度：`480（工作区）+ 24（门）+ 360（助手）= 864dp`；右栏上限 `1180dp`。常规侧栏 `88dp` 加 `1dp` 边线、无额外系统边距时，窗口最早 `953dp` 分屏；`945–952dp` 比当前实现晚 `8dp` 进入分屏。默认有效栏宽 50:50，再按两侧最小和右栏最大宽夹取；`1200dp` rail 加宽时重算，不重写用户比例。窄态依现有单路由接管，手机不出现门。
- 拖动预览与提交分开：实时调整两栏，达到可读下限后，实际交互槽留在夹取位置；另用不接收命中、不进入读屏的边缘提示表示超出，不把内容压到 0。接近边缘（沿用现行 `96dp` 吸附区，按可分配正文宽定义）且松手，向右收助手、向左收工作区（RTL 镜像）。取消、窗口宽度或实际栈顶变更、失去手势时丢弃预览，保留上次提交比例；不在 `build()` 写控制器或跨帧发旧几何。宽屏折叠态贴合隐藏侧保留连续细门轨，占宽不超过 `24dp`，在避开系统手势边界的安全位置可点按或向内拖；不另铺 `48dp` 全高热区。已有可见顶栏/导航的操作区提供 `48dp` 的「恢复分屏」替代动作，不新增栏宽，不覆盖编辑、返回或底栏。
- 收起只是展示模式，不 pop、不另建 `Navigator` 或 AssistantPage。保持原会话、未发文字/附件、当前轮生成、滚动和 Today 日期/滚动；隐藏子树暂停 UI 动画、退出读屏和焦点/键盘输入，但不停止生成。Tab 可达，方向键按现行 `40dp` 步进，读屏提供当前比例和增/减。门取得焦点后用 Home/End 切工作区/助手单栏，提供同名读屏动作，在无调宽空间时仍可用；收起态可 Enter/空格恢复。不抢输入框方向键。使用现有 `AppMotion`，减少动效时取消非跟手过渡。
- **回退矩阵**：宽屏两栏/仅助手/仅工作区是显式模式；临时缩窄、旋转、IME 与隐藏时不能覆盖设置的模式或比例。缩窄时，若显式选了仅工作区且聊天仍是实际栈顶，保持工作区，现有助手入口能恢复同一聊天并在窄窗接管；此时底部导航和当前任务栏不能被隐藏的详情栈吃掉。其他模式窄窗由同一聊天/详情路由接管。回到可分屏宽度恢复显式模式，除非用户已明确恢复/关闭。只有当前宽度能分屏、聊天是实际栈顶且处于手动折叠时，系统或顶栏返回才优先恢复两栏；窄窗不尝试恢复不可显示的布局。窄窗显式仅工作区且聊天隐藏时，系统返回按当前可见工作区处理，不能弹出看不见的聊天；用户主动切换对象、清理详情栈仍走既有守卫。聊天之上的历史、设置、详情、对话框和草稿保护优先执行原返回，不从底下恢复门或绕过确认。重点核对实际 Navigator 路由，包括[未登记入 `entries` 的历史/设置页](<../../lib/presentation/assistant/chat/assistant_page.dart#L1015-L1033>)。

实现入口：[AppShell 布局](<../../lib/app_shell.dart#L393-L562>)、[DetailPaneController](<../../lib/presentation/widgets/detail_pane.dart#L60-L186>)、[宿主返回](<../../lib/presentation/widgets/detail_pane.dart#L335-L379>)、[助手重入口](<../../lib/presentation/assistant/entry/assistant_scope.dart#L113-L147>) 和 [AssistantPage 顶栏](<../../lib/presentation/assistant/chat/assistant_page.dart#L307-L321>)。拖动范围、有效模式、点击/键盘/读屏仍走同一控制器；必要时用小型纯布局函数给测试断点和矩形，不增加第二套导航栈。在 50:50 之外不新增跨重启的分屏偏好。

### 5.2 导航居中

- 紧凑 rail 保持「图标在上、文字在下」，文字框横向中心对准图标、选中面和侧栏中线。宽 rail 保持图文同行，**图标＋标签组合居中**在整项中线，标签在自己的可用槽中居中；四项图标和标签各用相同槽宽，不因选中变粗或字重切换向左跳。品牌字标、底部助手头像随侧栏中线对齐；短窗口继续可滚动。
- 字号随系统，容器不足时图文改为上下、文字可两行，行高按实际文字增高；48dp 触控、Tooltip、选中读屏和 Tab 路径不变。选中底色跟真实目的项边界移动，不再按 1/4 估算。手机底部导航形态和页面保留逻辑不改。实现落点：[侧栏](<../../lib/app_shell.dart#L574-L729>)和[共享导航项](<../../lib/app_shell.dart#L856-L941>)；不要通过修改全局 `AppInteractiveSurface` 影响其他页面。

### 5.3 AI 发送

| 状态 | 外观和动作 |
| --- | --- |
| 空输入或不可发 | 与附件/麦克风同排，`36dp` 可见圆形浅中性底，`20dp` 上箭头；不会误导为可发送。 |
| 内容可发 | `36dp` 森林绿圆面、白色上箭头，保持同一个末端槽和按压/焦点反馈。 |
| 正在生成 | 原位切换 `36dp` 浅绿圆面/深绿停止图标，读屏「停止本轮」，不把停止做成另一处按钮。 |

用一个 `48×48dp` 真正可点、可键盘焦点且只产生一个语义节点的按钮承载三态；小圆面只绘制，不用 `Transform.scale` 缩点击区，也不改全局 IconButton 主题。附件、麦克风、思考、上下文环与发送触控槽等高、中心同线；极窄实际宽度不足时，次要工具可组到另一行，发送始终在末端，禁止把键盘避让或触控剪掉。保持[现有发送门禁和 IME 提交](<../../lib/presentation/assistant/chat/assistant_composer.dart#L26-L41>)、Enter/Ctrl+Enter、仅附件发送、停止本轮、草稿恢复及录音「完成」原义；不修改独立的系统悬浮聊天 UI。

## 6. 今天页：计划日程按面板宽度排版

```text
宽（列表）  [ 共同时间栏 ] [轨道 + 任务/进度]       [ 状态 / 专注 ][ › ]
            08:00          ● 品牌与营销管理实务              执行中  ›
            100 分钟         ━━━━━━━                      09:43
                             计划时段剩余 91 分钟
            14:00          ○ Python程序设计基础              待到时  ›
            100 分钟
窄（列表）  [轨道][ 任务名称可换行 ]                                 [ › ]
                 [ 开始 · 计划分钟 ][ 真实阶段 / 专注 ]（不足就换行）
```

- 一套内容边线：今日页头、日期带、各分区外框共用页面左右边距；同一列的「计划日程 / 自选时间 / 安排概览」使用同级内边距（高中密度 `16dp`，窄栏 `12dp`），区块间距 `16dp`，日期和卡头动作各靠另一端对齐。任务行内部用起止方向布局，非 RTL 专用硬编码。轨道宽 `16dp`，正文槽吸收剩余空间，末端箭头稳定在 `20dp` 槽；整行实际点击至少 `48dp`。不要为了齐线给没有轨道的其他页面加缩进。
- **宽列表样式**：计划卡内可用宽度 `≥ 480dp` 且按实际文字度量能给标题至少约 `160dp` 时启用。左侧时间/计划分钟分两行，名/辅助/进度进同一主列，右侧真实阶段/专注共享对齐基准，箭头单独占列；为 `23:59`、四位时长和最长状态按系统字号量槽，时间和状态同语义角色用等宽数字可用时启用。行高从内容自然增长。当前时段用一块浅强调面与轨道标记；进度条在正文槽内，剩余分钟在其下方（不和专注对抢宽），用文字明确它是**计划**进度。普通行保持开放底面和细分隔，不每条加大卡或插画。
- **窄列表样式**：不足时用同一任务项的纵向布局，标题优先、时间/计划时长、阶段/专注顺序换行；右箭头仍共线。首页标题最多两行并提供完整读屏名称；当日完整列表允许标题自然换行。在大字体与 320dp 下禁止强制固定行高、缩字体、单靠 ellipsis 丢阶段或把进度压成短划线。时区仅在需要时另行，不增加新查询。
- **工作区与当日入口**：布局基于 `LayoutBuilder` 的实际正文宽度（已扣侧栏/右栏/安全区/页边距），宽面板保留现有 `840dp` 起始阈值和 3:2 双区，间隙改共享 `16dp`；文字变大时继续按文字所需宽度回单区。宽仪表盘保留 `MissionTimetable`，左右区外沿与页头统一；Today 卡头「查看全部」在宽、窄都进**所选日期的当日日程**，顶栏「全部任务」继续进整周页。将首页「另有 N 项」合为底部短计数（若也可点，复用同一入口），不重复一行同文案。保留当日日程的「日程列表／时间轴」（原默认时间轴）及完整列表分页，不重作周表。首页仍 `2–4` 项，按可见高度和实际字高决定、不随右栏宽度拉伸；短屏可纵向滚动，已有选中日期、同日刷新和已展开自选状态不丢。
- **取值区分**：[today_display](<../../lib/presentation/today/today_display.dart#L182-L236>)继续提供当前时段和预览顺序，共用含 EXTEND 的 `plannedTimeSlotEnd`；`MissionLiveStatus` 用真实事件计算专注，STOP/待确认不可显示成仍执行；只有原本存在的信息才进对应槽。行点击仍调用 `_openDetail` 进入对应任务/阶段，保留空态、加载、刷新失败和「创建」入口。拖门、调字号和重排不额外发起读取、维护或写入。
