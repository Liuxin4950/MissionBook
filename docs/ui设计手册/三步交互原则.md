# 三步交互原则

2026-10-19。当前12页候选采用同一条硬约束：**每项功能的正常完整办理路径，不超过三次页面跳转。** 本文定义设计，应用实现仍须据此验收。

## 计数与保留上下文

从任一顶层页开始，切换顶层、进入独立工作页、系统选择进入、必需返回、保存后的强制结果页分别计一次。输入、滚动、筛选、真正保留对象及相邻列表的原位展开不计跳转。不能把独立全屏表单改叫弹窗后免计，也不能在执行→报告→材料同一业务链中重置计数。

操作次数可以多于三，必要校验、明确确认和权限不能省。计数针对一项功能的可发现正常路径及必经分支，不承诺用户主动先浏览多个可选详情、任意往返或连续办理多个独立功能后的总次数永远不超过三。

## 三种普通办理区域

- 今天任务行：保留日期列表、任务标题/阶段，原行展开方案、执行、报告与材料。其他任务仍可见或通过滚动访问。
- 目标卡：卡片箭头展开路径，节点标签展开任务摘要；保留目标标题/覆盖、相邻目标及顶层导航。维护、建任务和执行到材料可在该区域完成。完整目标详情、节点列表、任务详情是可选专注阅读页，不作为办理中转。
- 历史记录行：保留报告、Focus、相邻记录，原位整理材料、查看/修正正式材料、再次尝试与成功反馈。

原位区域必须保留真实来源与对象，展开后可滚动、可收起，不全屏替换列表。12张图是页面或状态参考，不能按图数串成12条路由。组件和导航约定已写入[正式界面规格](../v1.0/界面与交互.md)。

## 最坏起点的正常路径

| 功能 | 路径与必要反馈 | 最多跳数 |
| --- | --- | --- |
| 查看目标覆盖、切状态、树/节点维护、归档恢复 | 切目标1；卡内树及编辑/确认/结果原位 | 1 |
| 独立/节点建任务、编辑、改期、取消 | 切今天或目标1；可直接表单2，成功不强制离开；节点也可原位创建 | 2 |
| 开始→暂停/延长→报告→文字材料提交 | 切今天或目标1；在任务区完成整段办理 | 1 |
| 同上，包含文件/图片材料 | 切今天或目标1→系统选择2→回原草稿区3，提交及回执原位 | 3 |
| 当前RUNNING/PAUSED直达 | 任一顶层条件快捷栏→工作区1；报告/材料同区，系统选择2→返回3 | 3 |
| 待补、材料修正、重试 | 切历史1；记录行内展开与保存；若需系统选文件2→返回3 | 3 |
| 查看完整记录 | 切历史1→专注记录页2；阅读不写业务事实 | 2 |
| 手动/粘贴新目标 | 切目标1；创建区输入、校验、预览、确认及结果原位；独立表单可用第2跳 | 2 |
| JSON文件导入 | 切目标1→系统选择2→回目标创建区3；校验、树预览、确认及成功都在该区 | 3 |
| 备份 | 切我的1；说明/归档原位→系统保存2→返回原区3显示真实结果 | 3 |
| 通知或准时提醒授权 | 切我的1→对应系统授权/设置2→返回刷新3 | 3 |
| Android拍照材料 | 切今天/目标/历史1；相机权限请求2→返回3；取景、拍摄/重拍与确认嵌在草稿区 | 3 |
| 统计、日期、状态筛选、关于 | 切对应顶层1；原位操作 | 1 |

拍照不得再强制外部相机页面。系统设置若需要额外独立引导页，或平台文件API产生额外必经视图，须重新设计并计数，不能套用此表。取消、拒绝、读取失败均回原上下文保留可恢复输入；同次草稿的重选/重试不清零历史跳数，三步是首次正常办理的上限，异常恢复单独记录。

## 不能牺牲的业务条件

RUNNING冲突由用户明确处理；结束先暂停、确认才写END，未完成原因可空。强制材料截止、至少一项有效材料、原子保存、修正保留原件不变。Goal状态/归档有效性必须重验，不为少跳自动恢复状态。JSON必须校验和用户确认，备份先完成一致归档再系统保存。

[完整审查与证据](prototypes/三步可达审查.md)区分静态设计审查和运行验收。设计路径已经闭合；尚不代表程序或系统选择器已实测。
