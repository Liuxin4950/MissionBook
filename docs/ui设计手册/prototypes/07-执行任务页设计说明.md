## 控制与三步

暂停是高频主操作，结束为清楚可见的次级操作。直接暂停无需先填说明；暂停停止Focus增长，经过时间仍可增加。继续必须由用户明确点击，暂停期间追加额度不会自动继续。

延长只接受正整数分钟，改变当前额度，不覆盖原计划。达到额度可提示结束/继续，不自动END；超过额度仍显示实际Focus，圆环最多满环，不回绕伪造新周期。

结束先暂停RUNNING任务，再在同一任务工作上下文展开报告区域；返回报告保持暂停。固定任务身份、计划与只读方案不消失，不能另套一条独立“结束页→材料页→结果页”的必经长路由。报告、材料与系统往返继续按三步原则逐状态核对，不省掉明确确认或材料截止。

本例点击结束时应写第二次PAUSE于14:36:42，Focus锁定31:42；END尚未产生。后续报告与材料编辑时间不进入Focus。返回或关闭页面本身不等于暂停；真实计时应从事件和当前时间推导。
