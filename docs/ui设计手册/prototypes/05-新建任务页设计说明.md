## 本图时点与字段归属

样例承接22中用户已明确恢复并保存成功之后：Goal“建立阅读习惯”为ACTIVE、节点“阅读第一章”有效，父节点“阅读与记录”。Goal仍有效5节点、完成记录0/5。用户从该节点建任务，标题由节点预填，选择固定模式和强制材料并填写验收方向。本任务尚未创建，不提前写计划数、节点任务标签、执行事件或完成记录；与旧05中的“基础概念”草稿及已有setState任务无身份关系。

| 屏幕值 | 保存来源 / 校验 |
| --- | --- |
| 阅读第一章 | Mission.title，Trim非空；可编辑，不因为节点名变化而覆盖已编辑标题 |
| 2026-10-20，上海时间UTC+08:00 | ScheduleRevision.scheduledDate及timeZone=Asia/Shanghai；日历日期不是UTC时间串 |
| 30分钟 | plannedDurationMinutes，正整数；是计划投入，不是已有Focus或Current Budget |
| 固定，15:00 | FIXED；fixedStartAt对应上海2026-10-20 15:00，日期必须与scheduledDate匹配 |
| 强制材料 | Mission.verificationPolicy=REQUIRED_EVIDENCE；不是完成报告或验证结果 |
| 记录本章要点，附一段自己的理解。 | ExecutionPlan.verificationCriteria，用户本次填写的样例；该策略下Trim非空 |
| 2026-10-21 00:00 | evidenceDeadlineAt，上海排期次日零点；保存为2026-10-20T16:00:00Z |

图示当前为2026-10-20 14:00上海时间，因此截止晚于操作时刻及固定15:00。创建不自动开始，15:00到点也只提醒、不写START；用户可以提前明确开始。默认截止不是“固定开始+30分钟”，计划时长也不决定报告何时必须完成。实际默认日期取运行当天，不能硬编码样例。

“更多方案（选填）”收起，Why按入口的Goal Why预填（有值才带入）；objective初始采用任务标题，用户尚未单独修改时随标题更新；steps可为空。不能凭节点名称自动生成步骤、验收方向或AI评价。已独立编辑的方案值不被后续标题变化覆盖。

## 控件、跳转与保存

| 操作 | 画面 / 去向 | 数据边界与错误 |
| --- | --- | --- |
| 所属节点 | 同表单展开归属选择，可选Goal、有效节点或独立任务，保留当前输入 | 保存前重验ACTIVE与节点有效及同Goal；失效说明原因并由用户选择，不能擅自解除/更换归属 |
| 任务名称、计划时长 | 当前输入区编辑；数字键盘与滚动遵循平台 | 空标题、非正整数时长在原字段提示并定位；失败不清空其他值 |
| 日期 | 原表单内日历选择，不增完整向导页 | 改日期或时区时重设默认材料截止，明确呈现新最终值供保存确认；过去日期导致默认截止过期时提示错误，要求显式合法值，不自动推到未来 |
| 自选 / 固定 | 在设置行下原位展开或收起固定开始字段 | 固定必须有匹配排期日期的时刻；自选保存fixedStartAt=null，不能暗存旧固定时刻 |
| 固定开始 | 同表单内时间选择，保持日期可见 | 修改固定时刻须重新校验截止晚于该时刻；不自动START、不把已过计划时间判作失败 |
| 完成方式 | 原位展示自报完成/可选材料/强制材料选项 | 选中只改草稿，条件字段依策略展开；默认及切换差异见下表 |
| 验收方向 | 表单内开放写作区 | 可选/强制材料均必填，不能藏在“选填”的折叠区而遗漏校验 |
| 材料截止 | 同表单内日期与时间控件，持续显示上海时区及最终日期时间 | 必须晚于提交操作时刻；FIXED还晚于fixedStartAt，FLEXIBLE还晚于排期日期起点；时间不合法时保存不通过 |
| 更多方案 | 原位展开Why、具体目标、步骤、补充说明等 | 保留已输入内容及用户编辑标记；不额外创建新的方案路由 |
| 创建任务 | 原位提交中；一个事务创建Mission、ExecutionPlan及首个ScheduleRevision | 成功才反馈“任务已创建 · 待开始”，防重复；无START/END、无材料；失败整批回滚，保留所有输入及可恢复错误 |
| 查看今天 / 对应日期 | 创建成功后的可选动作，回指定日期任务列表并定位 | 不强制第四跳；留在原表单成功区也不再重复创建；关闭成功区按来源返回 |
| 返回 / 系统返回 | 有内容时确认放弃草稿；继续编辑保留全部，放弃回原入口 | 不能以返回当作取消已创建任务；提交结果未明时先查结果，避免重复创建 |

直接正常路径：其他顶层→目标1→节点行建任务表单2；树和节点选择在目标卡原位。若用户选择可选的03完整阅读，之后表单为第3跳，保存反馈仍在原处。今天→表单通常2跳。04节点任务已在第3跳时，复用本字段区原位办理，不强制第4跳。日历、时间、策略及归属控件均保留本次任务表单上下文，不把全屏新工作页改称弹窗以规避计数。

## 条件组件复用

| 状态 | 固定开始 | 验收方向 | 材料截止 |
| --- | --- | --- | --- |
| 默认FLEXIBLE + SELF_REPORT | 不展示，保存null | 可在方案中选填 | 不展示，保存null |
| FIXED + SELF_REPORT | 展示且必填 | 可在方案中选填 | 不展示，保存null |
| FLEXIBLE / FIXED + OPTIONAL_EVIDENCE | 按时间模式 | 展示且必填 | 不展示，保存null；无强制截止 |
| FLEXIBLE / FIXED + REQUIRED_EVIDENCE | 按时间模式 | 展示且必填 | 展示且必填，本图为FIXED组合 |

复用同一输入与设置行。切策略不丢弃用户已输入的方案文本，但隐藏的条件字段不能携带不符合新策略的旧值入库；验收方向在自报策略下仍可作为选填方案文本保存。截止编辑值可暂留本地草稿供切回查看，实际保存的条件字段必须按当前策略规范化并重新校验。日期/时区变化的默认截止重设规则优先，不能恢复旧日期的隐藏截止绕过校验。

待开始任务的编辑/改期复用本字段区，普通编辑标题“编辑任务”、主操作“保存修改”；不能伪装成新建并生成第二个Mission。排期有效修改或验证策略变化时追加完整排期版本；纯元数据编辑不重写排期和已保存截止。开始后归属、策略、方案与排期锁定。改期画面及保存/返回规则见[25](25-旧任务改期页设计说明.md)，普通编辑按两处组件映射复用；取消已保存的未开始任务见[26](26-取消任务确认页设计说明.md)，不复用创建草稿的放弃动作。

## 视觉与动画演进

独立表单不重复四项底部导航。顶部浅色返回；任务名采用普通输入角色18/24，避免把它放大成目标方向标题。日期与时长并排，设置使用平面行，写作区用细线明确边界，不堆满大圆角框。条件标签始终在输入值外，主操作用浅柑橘和森林文字；辅助时区14/20，设置/动作16/24，触达至少48逻辑像素。

选固定后固定开始从设置行下360ms展开，选择材料策略后验收方向与截止按条件依次显现；空间变化推动后续行，不遮盖旧字段。显隐180ms、按压140ms，曲线cubic-bezier(.22,.8,.24,1)。焦点留在触发设置，键盘出现时可滚动定位字段，不缩字号硬塞；创建按钮让位键盘和安全区。保存成功才替换为回执，失败保留草稿；减少动态效果时直接更新并保留条件标签、错误和焦点。
