# 页面跳转总表

2026-10-20。覆盖当前01—12主页面与13—29补充状态。下表标注设计关系；静态原型不代表路由或交互已经实现。对应原图及说明见[当前UI手册](../README.md)。

“原位”要求保留对应目标、任务或记录身份及所在列表的必要上下文。单独图片可表达不同工作状态，不等于必须增加一条路由。系统选择器的进入与必要返回分别计数，沿用[三步交互原则](../三步交互原则.md)。

## 四个顶层入口

01今天 ⇄ 02目标 ⇄ 11历史 ⇄ 12我的通过底部导航互达；切换保留各自筛选和滚动位置。有未提交内容时先执行当前编辑区的离开确认。RUNNING/PAUSED任务的条件快捷栏可以从任一顶层直达同一任务工作区。
