## 正常三步路径

其他顶层→目标1→建任务表单2；展开树不离开当前Goal，节点行建任务也到第2跳。用户可选完整03阅读后再进入表单，为第3跳，创建反馈仍留原上下文，不强制第4跳。节点任务完整列表也是可选，不作前置条件。

手动新建：其他顶层→目标1→13表单2→保存回目标3。文件导入：其他顶层→目标1→系统选择2→返回本页3，校验/预览/确认/反馈原位。当前任务从本页原位继续→报告→材料→反馈，只在系统选择及返回时再计2跳；独立07专注阅读不作正常含文件链的必经中转。反复主动选择/返回照实增加跳数，不把循环重试归零。

当前任务查询优先全局RUNNING，再最近PAUSED；没有二者时不在目标页用未开始任务冒充当前执行。本例只有所示PAUSED，故显示它。已暂停Goal或归档节点上的已有任务仍可执行，快捷栏不随当前Goal筛选消失；任务阶段与Goal状态分开判断。
