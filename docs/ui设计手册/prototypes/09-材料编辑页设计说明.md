## 提交、异常与返回

至少一条有效草稿才能提交；本图已有两条，按钮启用。主按钮为“提交材料”，首次整批原子保存后在同一工作区显示正式材料与回执，完整记录为可选展开。提交不写第二次END，不重算Focus；未来结果示例使用14:45为材料提交时刻，执行结束仍是14:37:15。

提交中阻止重复操作，失败保留内容和具体原因。准确截止在事务中再校验；到期时保留完成报告、记录材料超时，提示确认丢弃未提交草稿，不伪装提交成功。文件复制、超限、读取失败保留可恢复输入，不把失败附件当有效材料。

返回、系统返回均对有内容的草稿确认丢弃，确认只影响草稿，任务仍待补材料；不承诺进程退出恢复。修正正式材料复用编辑器但一次替代一条，按钮“保存修正”，保留原件，不重开任务或重置截止。

## 跳转与动效

材料编辑在原任务上下文展开，保留身份和摘要；验收、材料类型与草稿操作原位展开，提交回执原位替换。任一顶层条件当前任务栏直达工作区为1次，或切今天/目标/历史1次后在原任务区展开；系统文件选择进入与必要返回另计2次，共3次。目标卡内路径/任务原位展开已在总复核确定，不强制经过完整树和节点浏览页；设计计数见当前三步原则，静态图不证明应用运行已达标。
