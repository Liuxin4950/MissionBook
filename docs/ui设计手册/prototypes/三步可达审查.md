## 覆盖检查

以下不是只检查入口：每行包括必经条件和成功反馈。系统选择器进入和必要返回分别计一次；所有起点取另一顶层页的最坏情况。原位不成立时本表结论失效，必须按独立页重新计数。

| 规格中的功能 | 普通完整办理区域/路径 | 最大跳数 | 保留的条件 |
| --- | --- | --- | --- |
| 目标列表/覆盖/切状态/已放弃恢复 | 目标1，卡内状态与筛选原位 | 1 | 手动状态，覆盖不等于掌握 |
| 新建/编辑Goal | 目标1，原位创建或表单2，成功原位 | 2 | 明确保存 |
| JSON粘贴 | 目标1，输入/校验/树预览/确认原位 | 1 | 确认前无业务写入 |
| JSON文件 | 目标1→选择器2→返回原创建区3 | 3 | UTF8/大小/树深度/节点数/字段校验，原子确认保存 |
| 树/深层展开 | 目标1，目标卡内路径展开 | 1 | 不每层新开页面 |
| 节点新增/改名/说明/同级调序 | 目标1，树内编辑/保存 | 1 | 不跨Goal改父关系 |
| 归档/恢复节点 | 目标1，树内确认/归档筛选/恢复 | 1 | 子树归档、历史保留、父节点有效 |
| 浏览完整树/节点任务 | 目标1→完整树2→节点列表3 | 3 | 可选阅读链，不是操作强制中转 |
| 独立/Goal/节点创建Mission | 今天或目标1，原位表单或直接表单2 | 2 | 归属可见，保存重验，创建不START |
| 编辑/改期/取消Mission | 今天或目标1，对应行内编辑/确认/反馈 | 1 | 仅NOT_STARTED可改，取消需明确确认 |
| 全部任务/旧任务/其他暂停 | 今天1，原位列表与筛选 | 1 | 取消可查、不自动延期 |
| START/PAUSE/RESUME/EXTEND | 今天或目标1，任务区展开 | 1 | 单RUNNING，冲突明确处理；正整数延长，暂停不自动恢复 |
| 执行→自报/未完成报告→结果 | 同上1，报告确认与回执原位 | 1 | 先暂停，END只写一次；未完成原因可空 |
| 执行→可选/强制材料→文本类首次提交 | 同上1，任务/报告/材料保持连续 | 1 | 可选不交需明确选择，强制截止真实，至少一项有效 |
| 执行→文件/图片首次提交 | 同上1→系统选择2→返回3，提交原位 | 3 | 文件先准备、事务保存、失败保留草稿 |
| 拍照首次提交 | 对应顶层1→权限请求2→返回3；草稿内拍摄 | 3 | 仅Android能力支持；不额外外部相机/预览页 |
| 现有运行/暂停任务的直达办理 | 条件当前快捷栏→任务工作区1→文件选择2→返回3 | 3 | 快捷栏不重复当前任务，Phase重验 |
| 待补材料/超时处理 | 历史1，行内整理/确认/反馈；文件往返最多再2 | 3 | 全日期可查，保留完成报告，不写第二END |
| 记录/取消详情 | 历史1→专注只读详情2 | 2 | END倒序；取消无虚构Focus，运行无伪结果 |
| 材料正文/修正链 | 历史1，行内展开；完整记录可选2 | 2 | 有效项和历史链分开 |
| 文本材料修正 | 历史1，原项展开/保存 | 1 | 一次替代一项，旧记录与附件保留 |
| 文件/图片材料修正 | 历史1→系统选择2→返回3，原行保存 | 3 | 不重开Mission/不重算截止 |
| 再次尝试 | 历史1，保留原记录，原位新任务草稿与成功 | 1 | RETRY新Mission，不复制事件和正式材料 |
| 最近7天计划/完成、近30天格子 | 今天1，活动区原位查看 | 1 | 不相除为成功率，不冒称本周学习时长 |
| 日期/阶段/目标/材料筛选 | 对应顶层1，原位筛选和空/错状态 | 1 | 口径清晰，过去待办不丢失 |
| 通知/准时提醒能力设置 | 我的1→对应授权/系统设置2→返回刷新3 | 3 | 能力分别判断，不支持有说明，不阻塞手动执行 |
| 备份导出 | 我的1，范围/归档原位→系统保存2→返回3 | 3 | 一致快照与正式附件，缺件失败，不含草稿，不改源数据 |
| 关于 | 我的1，原位展开 | 1 | 实际包版本，无账号/AI配置占位 |

外部通知直达任务上下文并重新校验，不强制先回今天；停止若RUNNING先PAUSE，取消报告仍PAUSED。提醒延后15分钟属于提醒偏好，不改业务排期。启动/恢复/截止补算为生命周期行为，错误页重试不能写重复事件，不靠跳过确认满足本表。

## 审查边界

- 本表审查一项功能的正常办理及必经分支，不把“创建任务→之后执行任意多次→浏览若干详情→再次重试”无限串成一个功能；也不能把执行到强制材料这段业务链拆开重计。
- 完整阅读页是可选入口。正常操作须在顶层保留明确可发现的原位入口，不能只在文档里存在、落地又强制所有用户先进入阅读链。
- 异常重选/重试的系统往返继续累计，不能清零；记录真实恢复路径。首次正常主路径上限三跳，不承诺每次失败后无限重选仍≤3。
- 当前是静态设计审查，未调用真实Windows/Android选择器、权限、数据库或后台调度；实现若有额外必经视图，必须调整并实际验证。不能将文档表或自写路由计数当作程序通过的证据。
