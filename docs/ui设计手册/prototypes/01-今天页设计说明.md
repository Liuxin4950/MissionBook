在可检查的排版模型中测量，而不是从PNG反推逻辑尺寸：

- 390×844：正文区域宽390、高614，内容无横向溢出；六项、待处理入口均完整显示。
- 320×568：正文可视高338、内容高602，允许下滚；当前“开始”按钮底350，小于正文底464，首屏仍可操作。任务标题仍为18，没有缩字。
