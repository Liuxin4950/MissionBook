## 当前布局与事实边界

- 标题、日期选择、创建按钮与七天快捷日期；日期切换使用真实查询。
- 固定日程首页按屏高及字体展示2–4项连续窗口，空/单项自然收缩；“查看全部”只进入所选日期的完整固定日程。
- 当前计划时段使用强调面与计划进度，重叠时段分别判断；“查看”打开真实详情，不把高亮当作 START 或完成。
- 轨道连接任务顺序，不按分钟比例拉伸；首尾收进12像素，单项也有穿过节点的线。分钟/时段边界才重建，后台和隐藏停止刷新。
- 自选任务默认前三项，可展开收起；安排概览显示真实固定数、自选数及计划分钟。今天页不再显示底部已取消入口，数据保留，最终查询入口见业务规格。
- 标题16/24，正文、状态及计划14/20，区内操作14/20、600；短辅助12/16。完整日程允许标题换行，大字体自然增高，不缩字。240ms轻量过渡，减少动态效果时为0。
