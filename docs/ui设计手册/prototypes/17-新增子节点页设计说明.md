## 当前状态与归属

“建立阅读习惯”已保存且ACTIVE，已有4个有效节点，均无完成记录；全局进行中目标仍为4。用户在已有根节点“阅读与记录”的菜单中选择添加子节点，当前“每周复盘”只是未保存草稿。

两根仍为“选书”“阅读与记录”；“阅读第一章”“整理读书笔记”均属于后者。草稿位于这两个子节点之后，与它们同缩进；必须明确显示“新增子节点·未保存”和父节点语境。草稿不是第五条正式记录，当前覆盖仍0/4。

| 字段 / 关系 | 示例与保存条件 |
| --- | --- |
| title | 每周复盘；Trim后非空 |
| description | 回顾本周阅读，记下一个收获。可选，留空允许保存 |
| goalId | 沿用当前已保存目标ID，不由用户自由输入 |
| parentNodeId | 已保存“阅读与记录”的ID，同Goal且未归档；不是其他根或叶节点 |
| orderIndex | 本例同级没有归档项，两个已有子节点为0、1，新项成功后为2；一般情况必须包含归档同级维护连续顺序 |
| 其他字段 | 应用生成唯一ID和时间，archivedAt为空；不创建任务或事件，也不保存节点完成/掌握度 |

## 跳转、保存与返回

| 操作 | 画面去向 | 事实与失败处理 |
| --- | --- | --- |
| 父节点菜单→添加子节点 | 当前树枝下原位展开本编辑区，菜单关闭 | 父节点、同级、目标身份、邻项与导航保留；不新增独立工作页 |
| 编辑名称 / 说明 | 同区输入，键盘出现时滚动避让 | 不清空另一字段、不因收起而丢失本次草稿 |
| 保存节点 | 本区保存中，防重复点击 | 重新核对Goal存在、父节点有效且同Goal；名称合法后原子追加并维护同级顺序 |
| 保存成功 | 原草稿位置变为正式节点及局部回执，编辑区收起 | 节点数4→5，覆盖0/4→0/5，进行中目标仍4；“阅读与记录”子树从3节点变4节点；没有自动完成或新任务 |
| 保存失败 / 父节点已归档失效 | 本区说明原因，保留可恢复输入；父节点失效时停止提交 | 不留下半条节点、不自行恢复归档父节点、不把新项挂到其他父节点 |
| 取消 / 系统返回 / 切节点、筛选、目标、路径＋、页面新建＋或导航 | 有输入时确认丢弃；继续则回本草稿，放弃后恢复原树焦点再执行所选动作 | 不删除原有节点或改写任务；键盘返回先收键盘 |

最坏起点：其他顶层→目标1，卡内展开路径、父节点菜单、编辑、保存和成功反馈均原位，共1次页面跳转。完整03/04阅读视图仍可选，不是新增节点必经中转。

## 复用映射

新增根节点复用此编辑器，将父节点语境改为“目标根节点”、parentNodeId为空，输入在根层末尾展开；本图不得被误读为新增根节点。改名/编辑说明也复用名称与说明，按钮改“保存修改”，保留已有ID/Goal/父节点，不新增节点、不能当作跨Goal或改父关系入口。正式数量保持原值。

## 动效与视觉

父节点菜单选择后，草稿在正确子层位置360ms扩高，原有同级位置保持连续、后续内容随布局下移；输入内容180ms显现。保存中按钮不跳尺寸，提交成功后同一名称与说明承接到正式树行，再更新计数。失败不收起或播放成功动画。取消确认放弃后反向收起；减少动态效果时直接切最终布局，保留焦点和文字反馈。

树节点与节点名称输入均18/24；父节点/草稿状态和字段标签14/20，控制16/24。开放输入配底线，浅柑橘保存动作，避免每字段套方框。展开对象标题24/32与收起邻项18/24角色分明。视窗不足时滚动，不缩字号；节点说明允许自然换行，键盘不遮住保存/取消。
