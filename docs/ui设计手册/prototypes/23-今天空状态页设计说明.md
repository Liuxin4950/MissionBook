## 相似空状态的组件映射

| 条件 | 复用变化 | 不能丢失的真实数据 |
| --- | --- | --- |
| 仅所选日期无任务 | 日期照实，主文案“这一天没有安排”，复用空日程与创建入口 | 其他日期RUNNING/PAUSED仍以当前任务快捷栏可达；跨日期待补、以前未开始入口继续查询全局，统计不重置为0 |
| 全部任务筛选无匹配 | 主文案“没有符合条件的任务”，主动作改为“清除筛选”，原位恢复实际条件/结果 | 不能当作整个任务库为空，不能自动清空筛选或任务；已有执行及待补可达性保留 |
| 当天只有已取消记录 | 默认列表可为空，但保留“已取消N”折叠入口，N取真实查询 | 不把隐藏的取消项说成数据库没有任务；没有END、Focus或完成标记 |
| 已创建计划但暂无完成记录 | 近7天显示真实计划N、完成0；近30天可复用无完成记录文案 | 有任务的日程仍显示任务，不能因为无报告替换为本图全部空态 |

本图只实际绘制首次使用场景；以上是空组件在既定条件下的文案/入口复用规则，不声称跨日执行、全部任务筛选或待处理列表的专门视觉分支已经全部交付。初始化仍在进行时应显示可解释加载，失败时按启动错误处理，不提前展示此“成功但无数据”的正常状态。

## 动效与核对边界

无循环漂浮、闪烁计时或无限加载动画。正常空结果180ms显现，主动作按压140ms；展开日历/筛选360ms推动必要内容，保留日期及导航，不用全屏新页冒充原位。

明确创建并保存成功后，只有当新任务属于当前日期，空日程才360ms收为真实任务行，保持任务身份与“待开始”；不是点创建按钮就提前播放任务已存在的动画。保存失败保持空列表与表单草稿。首次完成报告成功后才按真实查询更新活动区，材料待补不遮盖已完成报告事实。曲线cubic-bezier(.22,.8,.24,1)，减少动态效果直接切换，保留状态文案与焦点。

暖白留白承担空态空间，不使用大插画、方框骨架或示例统计填满。小日历图标是日程提示，不表达完成。页标题28/36、空态标题24/32、区块/动作16/24、正文18/24、辅助14/20、导航12/16；触达至少48逻辑像素，键盘/窄屏行为仍沿用创建表单规则。
