## 问题与调整

| 原有问题 | 当前处理 | 元素实际含义 |
| --- | --- | --- |
| 卡片只有多行文字，缺少主次 | 明确目标名称、说明、状态与真实记录摘要；卡片保持白底，目录工具栏合并收起和添加 | 箭头和目录内容表达展开状态，不使用整块柑橘色模拟激活 |
| 节点编号、说明、数量、按钮层层堆叠 | 开放式树行、轻量连接线，优先节点名称和直接记录；说明随任务区展开 | 树箭头只展开孩子，记录标签只展开关联任务 |
| 任务区挤在节点标题旁的文字列里 | 展开区域使用整个节点宽度，任务日期、名称与动作重新对齐 | 不另起强制任务列表页，不复制执行状态机 |
| 每个节点动作都抢重点 | 所有节点“建任务”统一轻量文字动作，40可见高度与最小48触控范围分开 | 点击只准备草稿，不直接创建或 START |
| 详情用多张大卡展示说明和原因 | 名称与状态组成页首，说明/原因原位折叠，树直接铺在页面底上 | 折叠只改变可见性，不改业务数据 |
| 表单归属大绿块夹在多个输入区之间 | 顶部路径式归属，末级选项用浅柑橘；独立任务同样清晰可选 | 路径来自所选编号的真实查询，不由进入页面的路线猜测 |
| 预填说明占据首屏、默认具体目标可能与新名称脱节 | 名称、日期、时长优先，方案折叠；用户未单独编辑目标前随名称变化 | 一旦手动改过具体目标，不再被名称覆盖；编辑/重试保留原目标 |

记录摘要使用已有口径：有效节点总数为分母，每个节点只看直接关联任务的 COMPLETED END，按节点编号去重。父节点不继承孩子的记录；待补材料不抹去完成报告，归档节点不进入分母。无节点显示“暂无节点”，不是100%，也不表示掌握度或自动改为目标已达成。统计仅在页面读取并展示，不增加可写进度列。

空节点不再提供“展开任务”箭头或空白面板；说明通过节点编辑区仍可读写，任务区仅在有真实任务时展开。没有仅关联目标的任务时，卡片只保留“直接为目标建任务”快捷入口。折叠子树只保护被隐藏的后代工作区，父节点自己的报告保留；归档先确认范围，再检查这一子树的草稿。

全局按压反馈：取消扩散水波纹，文字/描边/图标动作使用主色6%按下、3%悬停、8%键盘聚焦反馈；深色主按钮使用相应白色反馈。局部设置前景色的目录按钮显式复用主题 overlay，防止框架默认样式覆盖。当前任务只依据 RUNNING/PAUSED 加细边框，不把列表第一项或展开状态当成“正在执行”。
