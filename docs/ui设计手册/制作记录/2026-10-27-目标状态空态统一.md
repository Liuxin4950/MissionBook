# 目标状态空态统一

用户实机截图显示：进行中空态有纸艺插画和分栏，而搁置、达成仅有横向提示，切换时缺少统一性。修订沿用现有目标纸艺素材、卡片、色彩和有限入场动效，三个主要分类以及已放弃的空态共享视觉骨架。不同状态保留准确文字和可操作入口；展示进行中目标时直接读取真实列表，最多显示三项，不生成示例目标或完成事实。已放弃查询只含已放弃目标，不用它推断其他状态。

宽屏将空态与真实目标或创建、导入操作并排；窄屏及大字体按实际空间纵向排列。空状态可返回进行中，真实目标可打开详情，创建和导入继续使用原有业务流程。导入草稿在状态切换及窗口缩放时保留。动效遵循系统减少动态效果设置。

复核截图来自隔离内存数据库的 Flutter 测试渲染，非用户数据：[搁置空态](../../教学/assets/ui-review-20261027/goals-empty-paused-no-active-1280.png)、[达成空态与真实进行中目标](../../教学/assets/ui-review-20261027/goals-empty-achieved-1280.png)。设备触控、屏幕阅读器和 Windows 实际窗口仍需实机验收。

## 文字层级与对齐

根据用户补充，目标页各分类沿用同一字号角色：页标题28/36，空态标题20/28，卡片/目标名称16/24，状态与说明14/20，主要操作16/24，分类选项14/20，输入15/22。空态插画、标题、说明和操作以卡片中心对齐；目标名称、说明、路径节点和输入内容按阅读顺序左对齐，分类标签在各自选项内居中。目标数量在空列表和有记录时都占相同位置，避免切换状态时分类栏跳动。导入输入与提示使用同一文字角色，预览目标名称与列表名称一致；节点说明和目标状态使用正文角色，而不是短标识字号。
