## 当前实现必须替换的内容

| 图片示意 | 当前处理 |
| --- | --- |
| Preferred 标签 | 当前只有 FIXED / FLEXIBLE，显示“固定时间 / 自选时间” |
| Evaluation、Verified、分数、AI 评语和建议 | 结果页只显示执行报告、时间、正式材料与“智能评价暂未接入” |
| 结果页返回按钮 | 仅导航，不触发确认关闭；提交材料成功时记录已经结束 |
| 英文页面标题、导航、按钮和标签 | 功能用中文，品牌和次级装饰英文可保留 |
| 正在学习、完成百分比 | 按领域规则显示行动记录标签与覆盖率，不宣称掌握度 |
| 创建任务或新增目标的示例按钮 | 依当前信息层级：目标页新建目标，节点树内新增节点，节点行写“建任务” |
| Add Evidence 中 Draft / Files / Camera / Note | 表达材料编辑入口，不是四个领域状态；Windows 使用文件选图 |
| End Mission 固定提示提交 Evidence | 随实际策略和用户报告变化，未完成和自报可以直接结束 |
| 执行子页重复出现的底部导航 | 子页面采用返回栈，不复制四个顶层页的导航 |
| 图中的任务、日期、评分与版本页脚 | 视觉样例，不是运行数据、发布日期或当前工程版本 |

History 与 Me 没有独立图片，按当前交互规格实现最小可用页面，沿用同一视觉语言。无需为了配齐图片生成模拟评价或虚构业务数据。

这些替换规则与原始图片共同构成当前视觉使用说明；原始图片本身不作为业务契约。
