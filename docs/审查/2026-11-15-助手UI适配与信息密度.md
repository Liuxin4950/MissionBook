# 助手 UI 适配与信息密度

用户要求修正前一天新增页面的分辨率适配、项目样式、间距和冗余说明。本轮以 `6d70614` 为基线，重点处理模型目录、服务配置、模型选择与编辑、消息分支及相邻助手设置和欢迎页。

## 发现与处理

| 页面或组件 | 已核实的问题 | 本轮调整 |
| --- | --- | --- |
| AI 模型总览 | 默认模型混入解释句，服务入口附带长说明，默认选择弹窗没有传入当前选中值 | 用“新会话默认模型”表达作用域，摘要明确显示跟随状态，恢复选中标记，停用模型收进展开区 |
| 服务编辑 | 宽屏仍使用单列，模型名称和编号重复，API Key 开关重复解释请求行为 | 连接与模型按空间分栏，状态紧邻开关，同名编号省略，停用和恢复使用带提示的图标 |
| 模型选择 | 列表高度直接乘整屏高度，长编号和键盘同时出现时可用空间不足 | 弹窗限宽 560、最大高 560，标题、搜索与惰性列表共用滚动视口，按键盘后的空间收缩 |
| 模型编辑 | 始终使用底部弹层，字段一直单列 | 复用 showAdaptiveSheet，手机底部、平板和桌面居中，容量与回复预算在空间足够时并排 |
| 助手设置 | 功能入口重复解释，阅读内容沿仪表盘限宽铺开，底栏实现与子页分散 | 阅读限宽 792，精简入口副标题，共用 AssistantSettingsForm 的草稿保护、反馈、保存和键盘避让 |
| 欢迎页 | 每个快捷动作都附带重复说明，大幅插画与多句介绍占据首屏 | 保留紧凑插画标题和六个图标动作，390 宽默认两列，大字号按空间回到单列 |
| 消息及分支操作 | 气泡以固定 44/68 底部留白容纳菜单，窄顶栏堆四个图标，编辑框缺少短屏滚动 | 用户菜单靠右留出触控区，回复操作随正文布局，手机模型切换显示可点击名称，消息菜单和编辑框可滚动 |

模型编辑还修正了非空、无法解析的输出硬上限被当作空值接受的问题，当前会显示输入错误。服务、凭据、模型与分支由控制器提交，各页面持有未保存草稿。

## 尺寸与交互约定

- 页面沿用 AppLayout 的暖白表面、森林绿、文字角色和 4/8/12/16 间距，区块间距 16。图标操作至少 48，主要保存操作至少 52，系统文字缩放参与布局。
- 模型总览和服务编辑的外框最大宽 1080。AdaptiveColumns 根据面板实际宽度和字号决定列数，正常字号的两栏各至少 480，间隔 16，因此内容区达到 976 才分两栏。窄宽切换保留同一 Wrap 子树、字段控制器和模型草稿。
- 协议与适配、上下文与回复预算按所在面板计算列数。模型编辑继续提供模型编号、名称、容量、回复预算、硬上限、思考程度与图片输入。
- 保存底栏将键盘高度纳入避让，短窗口允许底栏内部滚动。底栏登记在 Scaffold 的底部区域，复制等 SnackBar 显示在保存按钮上方。
- 手机保留新会话、历史和设置的直接入口。有会话时可点击模型名称切换，桌面保留原模型图标入口。消息编辑明确使用“新分支发送”，空正文时禁用发送。
- 图标保留 Tooltip 和原生操作语义，模型行提供编辑语义。模型选择使用 ListTile 的原生选中语义，提示框排除与可见标题重复的读屏文本。

布局依据以项目[全局样式](../架构/设计/全局样式/README.md)和实际面板为准，可用空间、输入方式和状态保留的核对同时参考 Flutter 的[自适应实践](https://docs.flutter.dev/ui/adaptive-responsive/best-practices)。

## 界面动效扩展

根据用户追加的界面设置、助手快捷按钮和主导航截图，增加可选风格和实际交互过渡。

| 区域 | 实现 |
| --- | --- |
| 页面与主导航内容 | 跟随平台、淡入、轻滑动、柔和缩放、上移进入、横向推入、淡出穿入；AppPageMotion 共用绘制，主导航的跟随平台使用短淡入 |
| 风格选择 | 图标与短标签，常规宽度双列，大字号按可用区域回到单列；选中底色、勾选和真实导航预览同步更新 |
| 底部导航与侧栏 | 选中底色移动，激活图标轻缩放，图标与文字颜色过渡；内容 State、滚动和输入保持原身份 |
| 助手快捷菜单 | 文字、语音从头像位置错峰展开，收起后移除；悬停、键盘焦点及长按滑动共用高亮和轻缩放 |
| 动效策略 | 复用 AppMotion 的 180/200/240/280ms，减少动效时立即显示最终状态；进行中切换同样生效 |

菜单根据实际字号扩大圆形触控区，并在横向空间不足时纵排。浮层通过 OverlayPortal.overlayChildLayoutBuilder 获取布局完成后的入口位置，根浮层与窗口坐标一致，关闭操作检查当前显示状态。复查期间发现的窗口重排读取未布局尺寸、浮层离开时重复关闭问题已修复，并加入连续关闭及 390→1440→768→320 缩放回归。

验证覆盖七种风格保存重载、Android 预测返回取消与提交、iOS 边缘返回取消与提交、每种风格的真实中间帧、切换风格保留输入、快速切主导航及减少动效中途切换。风格选择在 390×844、844×390、768×1024 下逐项操作，320 宽双倍字号验证滚动与末项选择；导航在 390/768/1280 宽验证指示器实际移动；快捷菜单在 320 双倍字号、844 横屏及 1440 宽验证展开、滑动激活与真实聊天入口。

`flutter test --no-pub test/presentation test/data/motion_settings_test.dart --reporter expanded --concurrency=4` 最终 481 项通过，包含 471 项页面回归与 10 项动效设置单元回归。`flutter analyze --no-pub` 无问题，25 个变更 Dart 文件格式检查和 CRLF 差异空白检查通过。

中文字体截图专项的三组快捷菜单交互通过。浏览器在 390×844、768×1024、1440×900 复核页面、七种选项、真实预览与快捷菜单，最终编译冷启动复查及菜单展开期间的跨导航形态缩放没有新增控制台错误。原生设备当前未连接 ADB，实际设备帧率、系统手势和 TalkBack 待验收。
