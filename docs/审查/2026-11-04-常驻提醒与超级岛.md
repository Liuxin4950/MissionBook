# 2026-11-04 常驻提醒与超级岛

用户要求清空其他提示后仍保留上课提醒，并补齐澎湃 OS 3 的灵动岛计时。检查发现课前、暂停和待确认通知均未设置 ongoing，只有运行中通知常驻；设置页也明确承认尚未发送小米模板。本轮补齐四种状态的常驻标记、完成应用侧超级岛协议，并将未开通平台服务与实际系统权限分别显示。

## 行为与边界

| 场景 | 当前行为 |
| --- | --- |
| 系统“全部清除” | 课前、运行、暂停及待确认四种通知保留；未来提醒继续调度。 |
| 点击正文 | 打开任务详情，通知由后续任务事实撤销。 |
| 取消/改期、提交 END | 原业务服务清理对应通知，不因常驻而残留。 |
| 运行计时 | 沿用累计 Focus，普通通知使用系统 Chronometer，超级岛模板使用同一起点的系统计时。 |
| 暂停、STOP 待确认、时钟回拨 | 显示冻结数字；小米模板不继续走秒。 |
| 不支持或未获准超级岛 | 普通常驻通知继续工作。 |
| 小米平台开通 | 用户确认目前尚未开通，先完成应用侧适配；未声称小米真机外观或鉴权通过。 |

Android 14 起仍允许用户解锁后单独划掉 ongoing 通知；本轮解决的是一键清空造成的误清除，未通过循环补发覆盖用户的主动操作。[Android 官方行为说明](https://developer.android.com/about/versions/14/behavior-changes-all#non-dismissable-notifications)

调用链、配置属性和小米模板来源统一见[平台资源总览](../架构/前端/平台资源/总览.md)。通知只展示原任务事实；STOP/END、序号、排期身份与事务仍由已有唯一业务核心处理。没有新增长期前台服务或逐秒后台通知循环。

## 实际验证

- 5 个相关测试文件共 39 项通过，覆盖常驻字段、原按钮和 payload、运行/暂停/待确认模板、长课存活期、时钟回拨、END 撤销及权限显示。
- Android 16 / API 36 x86_64 模拟器 profile 构建和真实通知集成用例通过。隔离内存数据库经过 MissionService 创建 START、PAUSE、STOP/reportPending 等真实事实，不打开正式业务库；提醒偏好和编号使用临时目录及独立编号区间。
- 实际点击系统“Clear all”：可清除的对照通知消失，四种任务通知编号均保留；尚未到提醒时刻的课程仍在插件的待调度列表；课程取消与用户提交 END 后对应通知撤销。
- 验证同一通知编号合法复用，以及取消后/新代次之后旧装饰调用不能复活或覆盖通知。
- 模拟器实际能力查询为 `islandSupported=false`、`focusConfigured=false`，没有通过修改系统设置或假装权限来声称上岛成功。准时提醒权限为 false，本轮不据此声称精确送达已验收。

## 复验

先在一个终端运行[设备交接脚本](../../test_driver/notification_device_handoff.py)，再在另一个终端运行[集成用例](../../integration_test/notification_delivery_test.dart)：

```powershell
python test_driver/notification_device_handoff.py emulator-5554

flutter drive --no-pub --profile --driver=test_driver/notification_delivery.dart --target=integration_test/notification_delivery_test.dart --dart-define=RUN_NOTIFICATION_AUDIT=true -d emulator-5554
```

交接脚本仅为隔离验收应用授予模拟器通知权限，在 `NOTIFICATION_AUDIT_READY` 时展开系统通知栏并保存截图。看到通知后，60 秒内手动点击系统“全部清除”；用例随后核对实际活动通知、未来调度、任务事实和撤销结果。脚本不依赖 UIAutomator 等待界面静止，原生秒表持续更新时该等待可能失败。

全仓静态分析退出 1，仅有开始工作前已存在的临时导入探针 `test/_tmp_import_probe_test.dart` 五条 avoid_print info；未修改或掩盖该文件。修改范围格式与差异空白检查通过。Android 构建保留现有 Kotlin/Java 兼容提示，本轮未升级工具链。

当前尚无用户手机的上岛、厂商清空通知策略或长期后台送达验收，也没有新增用户掌握证据。
