# 新手引导与封面（2026-11-17）

## 最终设计与范围

用户明确要求首次体验以视觉引导为主，避免低信息价值的说明段落堆叠，并喜欢 PPT 平滑切换式的连续关系。清新浅底、克制任务卡片与细线的方向已获用户认可；平板布局随后单独修正。视觉方向认可不等同于新版平板布局或原生设备体验已经得到最终验收。

- 三步内容为今天、目标、助手，每步只保留一个标题和一句提示。
- 同一张任务卡在步骤之间连续移动和改变尺寸，目标线随进度绘出；前后按钮、步骤跳转、方向键和触屏拖动共用进度，不循环漂浮。
- 封面使用原有品牌标识、名称及短标语，普通停留由 450ms 改为 2600ms；完成状态读回后可提前“进入”。减少动效跳过强制等待，不显示虚构加载进度。
- 完成与跳过共用原有本机完成标记，等待期间防重复，失败或回调异常可重试。
- 设置增加“帮助 → 使用引导”；通过根 Navigator 全窗口打开，关闭回到原设置，不改业务数据或重写完成标记。
- 未修改数据库结构、领域阶段、任务命令、权限策略或课程顺序。

## 手机与平板的布局

手机保留用户认可的上下阅读结构与底部操作区。平板处理窗口结构和示意内部关系，避免只缩放或换行：

| 环境 | 演示与操作的组织 |
| --- | --- |
| 手机、小窗口 | 原有 420×400 纵向示意；标题与短说明居中，操作在底部 |
| 平板竖屏与较窄宽屏 | 560×360 横向关系画布；演示、说明、步骤和按钮组成限宽纵向整体，画布最大宽 640 |
| 足够宽的平板横屏与桌面 | 左侧演示、右侧文案与操作；按钮跟随文案，不散落到整页底部 |
| 短横屏、大字号 | 回到可滚动内容与底部操作，保留必要返回和完整主按钮 |

布局按当前逻辑窗口选择：宽至少 600、高至少 560 且字号缩放小于 1.7 才进入平板组织；宽至少 960 且宽高比至少 1.05 才分列。竖屏不因宽度达到普通分栏断点就硬塞两列。旋转和窗口缩放保持当前步骤。

平板画布把“读完一本书 → 第一章 → 阅读 20 分钟”横向展开，手机继续使用紧凑纵向关系。示意不写演示任务、不调用真实模型，图片语义独立于主文案和按钮；主文案与操作响应系统字号。

### 实际入口发现与修复

首次从手机宽度打开设置后，旋转到平板横屏，原设置会进入已有的半屏详情工作区。若重看引导使用最近的 Navigator，也会被限制在这个半屏里，单独页面测试无法发现。浏览器实际发现该问题后，将重看入口改为 `Navigator.of(context, rootNavigator: true)`，增加“半屏设置打开全窗口引导、返回保留同一设置页面”的回归。
